Programa páginas web que responden a lo que hace el usuario

Cada unidad tiene la teoría explicada con ejemplos de código y actividades guiadas. Elige una unidad para empezar.

  1. Lee la teoría. Prueba los ejemplos en tu navegador: copia el código y ábrelo.
  2. Haz las actividades. Cada paso dice qué tienes que programar y cómo comprobarlo.
  3. Comprueba antes de entregar. Tu avance se guarda en este navegador.
