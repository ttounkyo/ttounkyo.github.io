Actividad 2.5. Lista de tareas

Una lista de tareas sencilla: escribes una tarea, pulsas el botón y aparece en la lista con un botón para borrarla. La construyes en tres niveles, de menos a más.

Lo que vas a practicar

  • Crear elementos con createElement y meter unos dentro de otros con appendChild
  • Añadir clases con classList.add
  • Buscar un texto dentro de otro con toLowerCase() e includes()
  • Crear botones desde JavaScript y darles su propio evento

Antes de empezar

  • Teoría: 7. El árbol DOM (y su «Ejercicio: lista de tareas») y 8. Eventos.

Paso a paso

  1. Crea los archivos

    Crea una carpeta con index.html (este código) y script.js vacío. La lista ul está vacía: las tareas se añadirán con JavaScript.

    <!DOCTYPE html>
<html lang="es">

<head>
    <meta charset="UTF-8">
    <title>Ejercicio JS: Crear Elementos</title>
    <style>
        .container {
            width: 50%;
            margin: auto;
        }

        .tarea {
            background: #f4f4f4;
            margin: 5px;
            padding: 10px;
            border-radius: 5px;
            list-style: none;
            display: flex;
            justify-content: space-between;
        }

        .urgente {
            border-left: 5px solid red;
        }
    </style>
</head>

<body>

    <h1>Mi Lista de Tareas</h1>

    <input type="text" id="inputTarea" placeholder="Escribe una tarea...">
    <button id="btnAgregar">Agregar Tarea</button>

    <div class="container">
        <ul id="listaTareas">
            <!-- Aquí se insertarán las tareas dinámicamente -->
        </ul>
    </div>

    <script src="script.js"></script>
</body>

</html>

  2. Nivel 1: crea la tarea

    En script.js, selecciona el campo, el botón y la lista. Cuando se haga clic en el botón (addEventListener):

    1. Lee el texto del campo y quítale los espacios de los extremos con trim().
    2. Si está vacío, avisa con alert("Escribe algo primero") y termina con return.
    3. Si no, crea un li, ponle el texto y añádelo a la lista.

  3. Nivel 2: clases y tareas importantes

    Añade a cada li nuevo la clase tarea (el CSS ya la tiene preparada: fondo gris y esquinas redondeadas).

    Si el texto de la tarea contiene la palabra «importante», escrita como sea (Importante, IMPORTANTE…), añade además la clase urgente, que le pone una raya roja a la izquierda. Pasa el texto a minúsculas con toLowerCase() y busca la palabra con includes("importante").

  4. Nivel 3: botón para eliminar

    Antes de añadir el li a la lista, crea un button con el texto «Eliminar» y mételo dentro del li. Al hacer clic en ese botón, se borra su tarea con remove().

    Cada botón borra solo su tarea porque se crea dentro de la misma función que su li y «recuerda» cuál es.

  5. Deja el campo listo para la siguiente

    Al terminar, vacía el campo (value = "") y vuelve a poner el cursor en él con focus(), para poder escribir la siguiente tarea sin hacer clic.

    Ver la solución

    Ver la solución funcionando (se abre en otra pestaña).

    // 1. Seleccionamos los elementos del DOM
const input = document.getElementById('inputTarea');
const boton = document.getElementById('btnAgregar');
const lista = document.getElementById('listaTareas');

// 2. Función para agregar la tarea
boton.addEventListener('click', () => {
    const texto = input.value.trim();

    // Validación: No permitir tareas vacías
    if (texto === "") {
        alert("Escribe algo primero");
        return;
    }

    // --- NIVEL 1: Crear el elemento ---
    const nuevaTarea = document.createElement('li'); // Creamos el <li>
    nuevaTarea.textContent = texto; // Le ponemos el texto

    // --- NIVEL 2: Clases y Limpieza ---
    nuevaTarea.classList.add('tarea'); // Añadimos la clase CSS

    if (texto.toLowerCase().includes("importante")) {
        nuevaTarea.classList.add('urgente');
    }

    // --- NIVEL 3: Botón de eliminar ---
    const btnBorrar = document.createElement('button');
    btnBorrar.textContent = "Eliminar";
    btnBorrar.onclick = function () {
        nuevaTarea.remove(); // Borra el elemento <li>
    };

    // Unimos las piezas
    nuevaTarea.appendChild(btnBorrar); // Metemos el botón dentro del li
    lista.appendChild(nuevaTarea);     // Metemos el li dentro de la lista (ul)

    // Limpieza
    input.value = "";
    input.focus();
});
