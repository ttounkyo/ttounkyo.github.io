Actividad 2.3. Validar un formulario

Un formulario de contacto no debería enviarse si falta un dato o el correo está mal escrito. Vas a comprobarlo con JavaScript antes de enviarlo, marcando en rojo o en verde cada campo y explicando el error debajo.

Lo que vas a practicar

  • Escuchar el evento submit de un formulario y detenerlo con preventDefault()
  • Leer lo que escribe el usuario con value y quitar espacios con trim()
  • Añadir y quitar clases CSS con classList
  • Comprobar un formato con una expresión regular y test()
  • Usar una variable de control (true/false) para el resultado final

Antes de empezar

  • Teoría: 8. Eventos (sobre todo «Evitar el comportamiento por defecto»), 5. Control de flujo y 3. Operadores.
  • La chuleta de 7. El árbol DOM (classList).

Paso a paso

  1. Crea los archivos

    Crea una carpeta con index.html (este código) y script.js vacío. El HTML ya trae los estilos para marcar los campos: la clase is-invalid pone el borde rojo y is-valid, verde. Debajo de cada campo hay un div vacío para el mensaje de error.

    <!DOCTYPE html>
<html lang="es">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Validación de Formulario</title>
    <style>
        body {
            font-family: sans-serif;
            max-width: 400px;
            margin: 40px auto;
        }

        form {
            display: flex;
            flex-direction: column;
            gap: 10px;
        }

        label {
            font-weight: bold;
        }

        input {
            padding: 8px;
            border: 1px solid #ccc;
            border-radius: 4px;
            /* Transición suave para el cambio de color del borde */
            transition: border-color 0.3s ease-in-out;
        }

        button {
            padding: 10px;
            background-color: #007bff;
            color: white;
            border: none;
            cursor: pointer;
            border-radius: 4px;
        }

        /* --- NUEVOS ESTILOS PARA VALIDACIÓN --- */

        /* Estilo para el input cuando es INVÁLIDO */
        .is-invalid {
            border-color: red;
        }

        /* Estilo para el input cuando es VÁLIDO */
        .is-valid {
            border-color: green;
        }

        /* Estilo para los pequeños mensajes de error debajo de cada input */
        .error-mensaje {
            color: red;
            font-size: 0.8em;
            /* Estará oculto hasta que tenga texto */
            min-height: 1.2em;
        }

        /* Estilo para el mensaje de éxito/error general */
        #mensaje {
            margin-top: 15px;
            font-weight: bold;
            text-align: center;
        }
    </style>
</head>

<body>

    <h1>Formulario de Contacto</h1>

    <form id="formulario" novalidate>

        <label for="nombre">Nombre:</label>
        <input type="text" id="nombre" placeholder="Escribe tu nombre">
        <!-- Contenedor para el error del nombre -->
        <div class="error-mensaje" id="nombre-error"></div>

        <label for="correo">Correo Electrónico:</label>
        <input type="email" id="correo" placeholder="Escribe tu correo">
        <!-- Contenedor para el error del correo -->
        <div class="error-mensaje" id="correo-error"></div>

        <button type="submit">Enviar</button>
    </form>

    <p id="mensaje"></p>

    <!-- Enlazamos nuestro archivo JavaScript al final del body -->
    <script src="script.js"></script>

</body>

</html>

    Fíjate en que el formulario tiene el atributo novalidate: así el navegador no hace sus propias comprobaciones y las haces tú con JavaScript.

  2. Selecciona los elementos y detén el envío

    En script.js, guarda en constantes el formulario, los dos campos, los dos div de error y el párrafo #mensaje.

    Después, escucha el evento submit del formulario. Lo primero que hace la función es llamar a event.preventDefault() para que la página no se recargue al pulsar Enviar.

    Declara también una variable esValido que empiece en true: cada vez que encuentres un error la pondrás a false.

  3. Borra el resultado anterior

    Como el usuario puede pulsar Enviar varias veces, al principio de cada comprobación deja todo como al principio: quita las clases is-valid e is-invalid de los dos campos (classList.remove(...)) y vacía los mensajes de error y el mensaje general.

  4. Comprueba el nombre

    Si el nombre está vacío (usa value.trim() para que no valga escribir solo espacios), añade la clase is-invalid al campo, escribe «El campo nombre es obligatorio.» en su div de error y pon esValido a false. Si no está vacío, añade la clase is-valid.

  5. Comprueba el correo

    El correo tiene dos comprobaciones: que no esté vacío («El campo correo es obligatorio.») y que tenga formato de correo («El formato del correo no es válido.»). Para el formato usa esta expresión regular, que comprueba que haya algo, una arroba, algo, un punto y algo más:

    // Una expresión regular sencilla para correos: "caracteres@caracteres.caracteres"
const regexCorreo = /^\S+@\S+\.\S+$/;

regexCorreo.test("ana@ejemplo.com"); // true
regexCorreo.test("ana.ejemplo.com"); // false

    Usa if ... else if ... else: vacío, formato incorrecto o válido.

  6. Muestra el resultado

    Al final, si esValido sigue siendo true, escribe en el párrafo #mensaje «Formulario enviado correctamente.» en verde. Si no, «Por favor, corrige los errores señalados.» en rojo.

    Prueba todos los casos: los dos campos vacíos, solo el nombre, un correo sin arroba y todo bien.

    Ver la solución

    Ver la solución funcionando (se abre en otra pestaña).

    // Seleccionamos los elementos del formulario una sola vez al cargar la página
const formulario = document.getElementById("formulario");
const nombreInput = document.getElementById("nombre");
const correoInput = document.getElementById("correo");

const nombreError = document.getElementById("nombre-error");
const correoError = document.getElementById("correo-error");
const mensajeGeneral = document.getElementById("mensaje");

// Esta es una Expresión Regular (RegEx) para validar emails de forma sencilla.
// Busca un patrón de "caracteres@caracteres.caracteres"
const regexCorreo = /^\S+@\S+\.\S+$/;

formulario.addEventListener("submit", function (event) {
    event.preventDefault(); // Evitamos el envío

    let esValido = true; // Usaremos esta variable para saber si el formulario es válido al final

    // --- Reseteamos los estilos y mensajes antes de cada validación ---
    nombreInput.classList.remove("is-valid", "is-invalid");
    correoInput.classList.remove("is-valid", "is-invalid");
    nombreError.textContent = "";
    correoError.textContent = "";
    mensajeGeneral.textContent = "";

    // --- Validación del Campo Nombre ---
    if (nombreInput.value.trim() === "") {
        nombreInput.classList.add("is-invalid"); // Añade clase de error
        nombreError.textContent = "El campo nombre es obligatorio.";
        esValido = false;
    } else {
        nombreInput.classList.add("is-valid"); // Añade clase de éxito
    }

    // --- Validación del Campo Correo ---
    if (correoInput.value.trim() === "") {
        correoInput.classList.add("is-invalid");
        correoError.textContent = "El campo correo es obligatorio.";
        esValido = false;
    } else if (!regexCorreo.test(correoInput.value.trim())) {
        // Usamos .test() para ver si el valor del correo cumple con la RegEx
        correoInput.classList.add("is-invalid");
        correoError.textContent = "El formato del correo no es válido.";
        esValido = false;
    } else {
        correoInput.classList.add("is-valid");
    }

    // --- Comprobación Final ---
    if (esValido) {
        mensajeGeneral.textContent = "Formulario enviado correctamente.";
        mensajeGeneral.style.color = "green";
        // Aquí podrías, por ejemplo, limpiar el formulario después de un envío exitoso
        // formulario.reset();
        // y quitar las clases de validación
        // nombreInput.classList.remove('is-valid');
        // correoInput.classList.remove('is-valid');
    } else {
        mensajeGeneral.textContent = "Por favor, corrige los errores señalados.";
        mensajeGeneral.style.color = "red";
    }
});
