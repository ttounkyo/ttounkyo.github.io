Actividad 2.6. Cartelera de películas

Una cartelera de películas hecha con Bootstrap: un formulario para añadir películas a una tabla, un botón para borrar cada una y una ventana (modal) para editarla.

Lo que vas a practicar

  • Añadir filas a una tabla desde un formulario (submit y preventDefault())
  • Crear una fila con innerHTML y rellenar sus celdas con textContent
  • Dar a cada fila sus propios botones de borrar y editar
  • Abrir y cerrar una ventana modal de Bootstrap desde JavaScript

Antes de empezar

  • Teoría: 7. El árbol DOM y 8. Eventos.
  • Haber hecho la Actividad 2.5 (lista de tareas): esta es parecida, pero con una tabla.
  • Conexión a Internet: Bootstrap se carga desde Internet.

Paso a paso

  1. Crea los archivos

    Fíjate en el orden de los scripts al final: primero el de Bootstrap y después el tuyo, porque tu código usa el objeto bootstrap.

  2. Añade películas a la tabla

    Escucha el evento submit del formulario formPelicula y, dentro:

    1. Llama a preventDefault() para que la página no se recargue.
    2. Lee el título, el género y la URL del póster.
    3. Crea una fila (tr) con cuatro celdas: el póster (una img con la clase img-tabla), el título (clase titulo-celda), el género (clase genero-celda) y una celda con dos botones, «Editar» y «Borrar».
    4. Añade la fila al tbody con id="cuerpoTabla" y vacía el formulario con reset().
    Cuidado con innerHTML: es cómodo para crear la estructura de la fila, pero no metas dentro lo que escribe el usuario. Si alguien escribe etiquetas HTML como título, el navegador las interpretaría (es un fallo de seguridad llamado XSS). Crea la fila con las celdas vacías y pon después los datos con textContent y src.

  3. Borra una película

    Dentro de la misma función, después de crear la fila, busca su botón «Borrar» (nuevaFila.querySelector(...)) y haz que al pulsarlo se borre esa fila con remove().

  4. Abre la ventana para editar

    Al pulsar «Editar», se abre el modal con los datos de esa fila ya escritos en sus campos. Para controlar el modal desde JavaScript, Bootstrap tiene el objeto bootstrap.Modal:

    // Al principio de script.js: el objeto que controla la ventana modal
const modalElemento = new bootstrap.Modal(document.getElementById('modalEditar'));

modalElemento.show(); // abre la ventana
modalElemento.hide(); // la cierra

    Escribe una función abrirModal(fila) que guarde en una variable cuál es la fila que se está editando, copie el título, el género y la URL de la fila a los campos editTitulo, editGenero y editUrl, y abra el modal. Asígnala al botón «Editar» de cada fila nueva.

  5. Guarda los cambios

    Al pulsar «Guardar Cambios» en el modal, copia los valores de los campos a la fila guardada, cierra el modal y vacía la variable de la fila.

    Prueba a añadir tres películas, editar la segunda y borrar la primera.

    Ver la solución

    Ver la solución funcionando (se abre en otra pestaña).

    const formPelicula = document.getElementById('formPelicula');
const cuerpoTabla = document.getElementById('cuerpoTabla');

// Variables para el modal
let filaAEditar = null;
const modalElemento = new bootstrap.Modal(document.getElementById('modalEditar'));

// --- FUNCION AGREGAR ---
formPelicula.addEventListener('submit', (e) => {
    e.preventDefault(); // Evita que la página se recargue

    const titulo = document.getElementById('titulo').value;
    const genero = document.getElementById('genero').value;
    const url = document.getElementById('urlImagen').value;

    const nuevaFila = document.createElement('tr');
    // Con innerHTML creamos la estructura de la fila (celdas vacías)...
    nuevaFila.innerHTML = `
        <td><img class="img-tabla shadow-sm" alt=""></td>
        <td class="titulo-celda fw-bold"></td>
        <td class="genero-celda"></td>
        <td class="text-center">
            <button class="btn btn-sm btn-warning me-2 btn-editar">Editar</button>
            <button class="btn btn-sm btn-danger btn-eliminar">Borrar</button>
        </td>
    `;
    // ...y los datos que escribe el usuario los ponemos con textContent y src.
    // Así, si alguien escribe etiquetas HTML en el título, se ven como texto y no se ejecutan.
    nuevaFila.querySelector('img').src = url;
    nuevaFila.querySelector('img').alt = `Póster de ${titulo}`;
    nuevaFila.querySelector('.titulo-celda').textContent = titulo;
    nuevaFila.querySelector('.genero-celda').textContent = genero;

    // Evento Eliminar
    nuevaFila.querySelector('.btn-eliminar').onclick = () => nuevaFila.remove();

    // Evento Abrir Modal de Edición
    nuevaFila.querySelector('.btn-editar').onclick = () => abrirModal(nuevaFila);

    cuerpoTabla.appendChild(nuevaFila);
    formPelicula.reset(); // Limpiar formulario
});

// --- FUNCION ABRIR MODAL Y LLENAR DATOS ---
function abrirModal(fila) {
    filaAEditar = fila; // Guardamos la fila que queremos modificar

    // Cargamos los datos actuales de la fila en los inputs del modal
    document.getElementById('editTitulo').value = fila.querySelector('.titulo-celda').textContent;
    document.getElementById('editGenero').value = fila.querySelector('.genero-celda').textContent;
    document.getElementById('editUrl').value = fila.querySelector('img').src;

    modalElemento.show(); // Mostramos el popup
}

// --- FUNCION GUARDAR CAMBIOS ---
document.getElementById('btnGuardarCambios').onclick = () => {
    if (filaAEditar) {
        // Actualizamos los valores de la fila guardada
        filaAEditar.querySelector('.titulo-celda').textContent = document.getElementById('editTitulo').value;
        filaAEditar.querySelector('.genero-celda').textContent = document.getElementById('editGenero').value;
        filaAEditar.querySelector('img').src = document.getElementById('editUrl').value;

        modalElemento.hide(); // Cerramos el popup
        filaAEditar = null;    // Limpiamos la referencia
    }
};
