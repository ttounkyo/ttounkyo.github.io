Actividad 2.7. Tablero de colores

Un tablero de cuadrados oscuros que se iluminan de colores al pasar el ratón y se apagan poco a poco. El programa pregunta cuántos cuadrados quieres y comprueba que la respuesta sea válida.

Lo que vas a practicar

  • Crear muchos elementos con un bucle for
  • Eventos del ratón: mouseover y mouseout
  • Comprobar lo que escribe el usuario: vacío, que sea un número y que esté en un rango
  • Repetir una pregunta con un bucle while hasta que la respuesta sea válida
  • Seleccionar elementos con querySelectorAll y acceder a uno por su posición

Antes de empezar

  • Teoría: 6. Bucles, 5. Control de flujo y 8. Eventos.

  2. Crea los cuadrados

    Escribe una función generarCuadrados() que:

    1. Pregunte con prompt cuántos cuadrados quiere el usuario y lo convierta a número con parseInt().
    2. Con un bucle for, cree ese número de div con la clase square, les ponga como texto su número (1, 2, 3…) y los añada al contenedor #container.

    Llama a la función al final de script.js para que se ejecute al abrir la página.

  3. Ilumina los cuadrados al pasar el ratón

    Dentro del bucle, a cada cuadrado añádele dos eventos con addEventListener:

    • mouseover (el ratón entra): pon un color de fondo aleatorio. Si quieres que brille, pon también una sombra del mismo color: style.boxShadow = `0 0 10px ${color}`.
    • mouseout (el ratón sale): quita el color asignando una cadena vacía. El cuadrado vuelve al color del CSS poco a poco gracias a la transición.

    Para el color aleatorio puedes usar esta función:

    function generarColorAleatorio() {
    const letras = "0123456789ABCDEF";
    let color = "#";
    for (let i = 0; i < 6; i++) {
        color += letras[Math.floor(Math.random() * 16)];
    }
    return color;
}

    Pasa el ratón por el tablero: debe quedar una estela de colores que se apaga.

  4. Comprueba la respuesta del usuario

    ¿Qué pasa si el usuario deja la respuesta vacía, escribe «hola» o pide un millón de cuadrados? Escribe una función pedirNumero(mensaje, minimo, maximo) que repita la pregunta con un bucle while hasta que la respuesta sea válida y la devuelva como número:

    • Si está vacía: «No puede estar vacío.»
    • Si no es un número (Number.isNaN(parseInt(respuesta))): «Tiene que ser un valor numérico.»
    • Si está fuera del rango: «El número tiene que estar entre 1 y 500.»
    • Si el usuario pulsa Cancelar (prompt devuelve null), la función devuelve null y no se crea nada.

    Usa esta función en generarCuadrados() en lugar del prompt directo.

  5. Cambia el color de un cuadrado concreto

    Haz que el botón «Cambiar el color de un cuadrado» llame a una función cambiarColor() que:

    1. Seleccione todos los cuadrados con querySelectorAll(".square").
    2. Pregunte, con pedirNumero, a qué cuadrado hay que cambiarle el color (entre 1 y el número de cuadrados).
    3. Le ponga un color aleatorio. Ojo: el cuadrado número 1 está en la posición 0 de la lista.
    Ver la solución

    Ver la solución funcionando (se abre en otra pestaña).

    // Tablero de colores: cuadrados que se iluminan al pasar el ratón
const contenedor = document.getElementById("container");
const botonCambiar = document.getElementById("btnCambiar");

// Devuelve un color hexadecimal aleatorio, por ejemplo "#3FA2C9"
function generarColorAleatorio() {
    const letras = "0123456789ABCDEF";
    let color = "#";
    for (let i = 0; i < 6; i++) {
        color += letras[Math.floor(Math.random() * 16)];
    }
    return color;
}

// Pregunta un número hasta que sea válido. Devuelve el número, o null si el usuario pulsa Cancelar
function pedirNumero(mensaje, minimo, maximo) {
    while (true) {
        const respuesta = prompt(mensaje);

        if (respuesta === null) {
            return null; // ha pulsado Cancelar
        }

        const numero = parseInt(respuesta);

        if (respuesta.trim() === "") {
            alert("No puede estar vacío.");
        } else if (Number.isNaN(numero)) {
            alert("Tiene que ser un valor numérico.");
        } else if (numero < minimo || numero > maximo) {
            alert(`El número tiene que estar entre ${minimo} y ${maximo}.`);
        } else {
            return numero; // es válido: salimos de la función
        }
    }
}

function agregarColor(cuadrado) {
    const color = generarColorAleatorio();
    cuadrado.style.backgroundColor = color;
    cuadrado.style.boxShadow = `0 0 2px ${color}, 0 0 10px ${color}`;
}

function quitarColor(cuadrado) {
    // Al quitar el estilo, vuelve el color del CSS poco a poco (por la transición de 1 s)
    cuadrado.style.backgroundColor = "";
    cuadrado.style.boxShadow = "";
}

function generarCuadrados() {
    const cantidad = pedirNumero("¿Cuántos cuadrados quieres? (entre 1 y 500)", 1, 500);
    if (cantidad === null) {
        return;
    }

    for (let i = 1; i <= cantidad; i++) {
        const cuadrado = document.createElement("div");
        cuadrado.classList.add("square");
        cuadrado.textContent = i;

        cuadrado.addEventListener("mouseover", () => agregarColor(cuadrado));
        cuadrado.addEventListener("mouseout", () => quitarColor(cuadrado));

        contenedor.appendChild(cuadrado);
    }
}

// Pregunta a qué cuadrado hay que cambiarle el color y se lo cambia
function cambiarColor() {
    const cuadrados = document.querySelectorAll(".square"); // NodeList
    if (cuadrados.length === 0) {
        alert("Todavía no hay cuadrados.");
        return;
    }

    const numero = pedirNumero(`¿A qué cuadrado quieres cambiarle el color? (entre 1 y ${cuadrados.length})`, 1, cuadrados.length);
    if (numero !== null) {
        cuadrados[numero - 1].style.backgroundColor = generarColorAleatorio();
    }
}

botonCambiar.addEventListener("click", cambiarColor);
generarCuadrados();
