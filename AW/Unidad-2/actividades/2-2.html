Actividad 2.2. Tarjeta de producto

Tienes la tarjeta de un producto de una tienda online, con su HTML y su CSS. Sin tocar el HTML, vas a cambiar con JavaScript el título, el precio, la imagen y el botón de comprar.

Lo que vas a practicar

  • Seleccionar elementos con getElementById
  • Cambiar el texto de un elemento (innerText o textContent)
  • Cambiar estilos con style y atributos con setAttribute
  • Reaccionar a un clic con addEventListener y deshabilitar un botón

Antes de empezar

  • Teoría: 7. El árbol DOM y 8. Eventos.
  • Repasa cómo se enlaza un archivo .js: la etiqueta script.
Qué entregas
Archivo ApellidoNombre_AW_Actividad2.2.zip
Contenido Una carpeta con index.html y script.js, comprimida en .zip
Cómo comprobar tu código: guarda los archivos y abre el .html con el navegador (doble clic o arrástralo a una pestaña). Pulsa F12 y mira la pestaña Consola: si hay un error, aparece en rojo con el nombre del archivo y la línea. Cada vez que cambies el código, guarda y recarga la página con F5.

Las imágenes de ejemplo vienen del servicio gratuito placehold.co, que genera imágenes con un texto. Si algún día no cargan, usa la URL de cualquier otra imagen: lo importante es que cambie el atributo src.

Paso a paso

  1. Crea los archivos

    Crea una carpeta para la actividad y, dentro, dos archivos: index.html con este código y script.js vacío. Abre index.html en el navegador: verás la tarjeta de un «Producto Genérico» de 0,00 €.

    Todo el JavaScript de esta actividad va en script.js. El HTML ya lo enlaza al final del body con <script src="script.js"></script>.

  2. Cambia el título

    El título actual es «Producto Genérico». Selecciona el elemento por su ID (producto-titulo) y cámbialo por Increíble Teclado Mecánico.

  3. Actualiza el precio

    El precio es «0,00 €». Selecciona el elemento producto-precio y actualízalo a 99,99 €.

  4. Aplica un estilo de oferta

    Para que el nuevo precio llame la atención, cambia su color a verde (green) y ponlo en negrita. En JavaScript, las propiedades CSS con guion se escriben juntas y con mayúscula: font-weight es style.fontWeight.

  5. Cambia la imagen del producto

    La imagen actual es un marcador gris. Selecciona la imagen (producto-imagen) y cambia su atributo src para que muestre esta otra:

    https://placehold.co/400x300/0000FF/FFFFFF.png?text=Teclado

  6. Haz el botón interactivo

    Cuando el usuario haga clic en el botón «Comprar», su texto debe cambiar a ¡Añadido al carrito! y el botón debe deshabilitarse para que no se pueda volver a pulsar (propiedad disabled). Usa addEventListener("click", ...).

    Recarga la página y comprueba que la tarjeta muestra el teclado, el precio en verde y que el botón cambia al pulsarlo.

    Ver la solución

    Ver la solución funcionando (se abre en otra pestaña).

    // 1. Seleccionamos el elemento del título por su ID
const tituloProducto = document.getElementById('producto-titulo');
// Cambiamos su contenido de texto
tituloProducto.innerText = 'Increíble Teclado Mecánico';

// 2. Seleccionamos el elemento del precio
const precioProducto = document.getElementById('producto-precio');
// Actualizamos su texto
precioProducto.innerText = '99,99 €';

// 3. Aplicamos estilos al precio que acabamos de seleccionar
precioProducto.style.color = 'green';
precioProducto.style.fontWeight = 'bold';

// 4. Seleccionamos la imagen
const imagenProducto = document.getElementById('producto-imagen');
// Cambiamos su atributo 'src' para que muestre una nueva imagen
imagenProducto.setAttribute('src', 'https://placehold.co/400x300/0000FF/FFFFFF.png?text=Teclado');

// 5. Hacemos el botón interactivo
// Primero, seleccionamos el botón
const botonComprar = document.getElementById('boton-comprar');

// Luego, añadimos un "escuchador de eventos" para el 'click'
botonComprar.addEventListener('click', function () {
    // Este código se ejecutará SOLO cuando se haga clic en el botón

    // Cambiamos el texto del botón
    botonComprar.innerText = '¡Añadido al carrito!';

    // Deshabilitamos el botón
    botonComprar.disabled = true;
});
