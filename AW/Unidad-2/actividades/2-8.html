Actividad 2.8. Repaso de JavaScript

Seis preguntas para repasar toda la unidad: en las tres primeras lees un código y explicas qué hace; en las tres últimas escribes tú el código. Intenta responder sin mirar y después compara con la respuesta.

Lo que vas a practicar

  • Leer código y explicar qué hace, línea a línea
  • prompt, alert y condicionales
  • Seleccionar elementos y cambiar su texto, su estilo y sus atributos
  • Eventos con addEventListener

Antes de empezar

  • Teoría: toda la unidad, sobre todo 1. Introducción, 7. El árbol DOM y 8. Eventos.
  • Las actividades 2.1 y 2.2: las preguntas se parecen mucho a lo que hiciste en ellas.

Paso a paso

En las preguntas 1 a 3, explica qué hace el código: qué elementos selecciona, qué modifica y cuál es la lógica. En las preguntas 4 a 6, escribe el código; supón que el HTML ya contiene los elementos con los identificadores que se mencionan.

  1. Pregunta 1. ¿Qué hace este código? (prompt)

    let respuesta = prompt("¿Cuál es tu color favorito?");
if (respuesta !== "") {
    alert("Tu color favorito es " + respuesta);
} else {
    alert("No has introducido ningún color.");
}

    ¿Qué hace? ¿Qué pasa si el usuario pulsa Cancelar?

    Ver la respuesta

    Muestra una ventana (prompt) que pregunta «¿Cuál es tu color favorito?» y guarda lo que escribe el usuario en la variable respuesta. Después comprueba si la respuesta es distinta de la cadena vacía:

    • Si ha escrito algo, por ejemplo «verde», muestra una alerta: «Tu color favorito es verde».
    • Si ha dejado el cuadro vacío y ha pulsado Aceptar, muestra «No has introducido ningún color.».

    Ojo: si pulsa Cancelar, prompt devuelve null, que es distinto de "", así que la alerta dice «Tu color favorito es null». Para tratar los dos casos igual, basta con comprobar if (respuesta):

    const respuesta = prompt("¿Cuál es tu color favorito?");
if (respuesta) { // falso con "" y con null
    alert("Tu color favorito es " + respuesta);
} else {
    alert("No has introducido ningún color.");
}

  2. Pregunta 2. ¿Qué hace este código? (un título)

    const titulo = document.getElementById("titulo-principal");
titulo.innerText = "Bienvenido a la página";
titulo.style.color = "blue";
    Ver la respuesta
    1. Busca en la página el elemento con id="titulo-principal" y lo guarda en la constante titulo.
    2. Sustituye su texto por «Bienvenido a la página» (lo que tuviera antes desaparece).
    3. Cambia el color de su texto a azul con el estilo en línea color: blue.

    Si en la página no existe ningún elemento con ese ID, getElementById devuelve null y la segunda línea da un error en la consola (Cannot set properties of null).

  3. Pregunta 3. ¿Qué hace este código? (un botón)

    const boton = document.getElementById("miBoton");
boton.addEventListener("click", function() {
    let nuevoParrafo = document.createElement("p");
    nuevoParrafo.innerText = "Has hecho clic en el botón";
    document.body.appendChild(nuevoParrafo);
});
    Ver la respuesta
    1. Busca el botón con id="miBoton" y lo guarda en boton.
    2. Le añade un manejador del evento click: la función no se ejecuta ahora, sino cada vez que se hace clic en el botón.
    3. En cada clic, crea un párrafo nuevo (p), le pone el texto «Has hecho clic en el botón» y lo añade al final del body.

    Resultado: cada clic añade otro párrafo igual debajo de los anteriores. Con tres clics, verás el texto tres veces.

  4. Pregunta 4. Escribe el código: cambiar una imagen

    Escribe el código para seleccionar una imagen con el identificador foto-perfil y cambiar su atributo src para que muestre la imagen nueva-foto.png. Supón que el HTML ya tiene la imagen.

    Ver la respuesta 
    const foto = document.getElementById("foto-perfil");
foto.src = "nueva-foto.png";

// También vale:
// foto.setAttribute("src", "nueva-foto.png");

  5. Pregunta 5. Escribe el código: verificar la edad

    Escribe una función llamada verificarEdad() que pregunte al usuario su edad con prompt. Si la edad es mayor o igual que 18, debe mostrar una alerta que diga «Eres mayor de edad». Si es menor, una alerta que diga «Eres menor de edad».

    Ver la respuesta 
    function verificarEdad() {
    // prompt devuelve texto: lo convertimos a número
    const edad = Number(prompt("¿Cuántos años tienes?"));

    if (edad >= 18) {
        alert("Eres mayor de edad");
    } else {
        alert("Eres menor de edad");
    }
}

verificarEdad(); // para probarla

    Convertimos con Number() porque prompt devuelve texto. Sin convertir, "20" >= 18 también funcionaría (JavaScript convierte el texto al comparar), pero es mejor no depender de esas conversiones automáticas.

  6. Pregunta 6. Escribe el código: desactivar un botón

    Escribe el código para seleccionar un botón con el identificador btn-desactivar y, al hacerle clic, cambiar su texto a «Desactivado» y deshabilitarlo (pista: usa la propiedad disabled).

    Ver la respuesta 
    const botonDesactivar = document.getElementById("btn-desactivar");

botonDesactivar.addEventListener("click", function () {
    botonDesactivar.textContent = "Desactivado";
    botonDesactivar.disabled = true;
});

    Un botón con disabled = true se ve gris y ya no responde a los clics.
