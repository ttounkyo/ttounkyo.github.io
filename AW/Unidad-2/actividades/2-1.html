Actividad 2.1. Primeros programas

Cinco programas cortos para empezar: botones que muestran mensajes, preguntas al usuario, condiciones y un contador. En cada paso tienes un código que ya funciona: pruébalo y después amplíalo con lo que se pide.

Lo que vas a practicar

  • Las funciones alert, prompt y confirm
  • Escribir y llamar a funciones
  • Condicionales if...else (y, si quieres, switch)
  • Seleccionar elementos con getElementById y cambiar su texto y su estilo
  • Crear elementos con createElement y appendChild
  • Asociar eventos con addEventListener

Antes de empezar

  • Teoría: 1. Introducción a JavaScript (sobre todo «Mostrar mensajes y pedir datos»), 2. Conceptos básicos y 5. Control de flujo.
  • Para los pasos 4 y 5: 7. El árbol DOM y 8. Eventos.
  • Un editor de código (por ejemplo, Visual Studio Code) y un navegador.

Paso a paso

  1. Botón con alerta

    Crea el archivo ejercicio1.html, copia este código y ábrelo en el navegador. Al pulsar el botón aparece un mensaje.

    <!DOCTYPE html>
<html lang="es">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ejercicio 1: Botón con alerta</title>
</head>

<body>

    <h1>Ejercicio 1: Botón con alerta</h1>

    <!--
        El atributo 'onclick' ejecuta el código JavaScript que contiene
        cuando el usuario hace clic en este botón.
    -->
    <button onclick="alert('Bienvenido/a a mi página web')">
        Púlsame
    </button>

    <h2>¿Cómo funciona?</h2>
    <ul>
        <li><code>&lt;button&gt;</code>: es la etiqueta estándar de HTML para crear un botón.</li>
        <li><code>onclick="..."</code>: es un "atributo de evento". Le dice al navegador: "cuando alguien haga clic en
            este elemento, ejecuta el código que está entre las comillas".</li>
        <li><code>alert('...')</code>: es una función de JavaScript que muestra una ventana emergente con el mensaje que
            le pases entre paréntesis.</li>
    </ul>

</body>

</html>

    Ahora amplíalo como hicimos en clase, con prompt, confirm y createElement. Añade un segundo botón que llame a una función alerta() que:

    1. Pida el nombre al usuario con prompt.
    2. Si no ha escrito nada, le avise con alert y vuelva a empezar.
    3. Si ha escrito un nombre, le pregunte con confirm si de verdad es esa persona.
    4. Si confirma, cree un párrafo con el texto «Bienvenido/a nombre a mi página web» y lo añada al final del body. Si no confirma, le avise y vuelva a empezar.

    La función se escribe dentro de una etiqueta <script> antes de cerrar el </body>.

    Ver la solución (lo que hicimos en clase) 
    <button onclick="alerta()">Click me</button>

<script>
    function alerta() {
        // Pedimos el nombre al usuario
        const nombre = prompt("Introduce tu nombre");

        // Si pulsa Cancelar, prompt devuelve null: no hacemos nada más
        if (nombre === null) {
            return;
        }

        if (nombre.trim() !== "") {
            // Pedimos confirmación
            const ok = confirm(`¿Estás seguro de que eres ${nombre}?`);
            if (ok) {
                // Creamos un párrafo, le ponemos el texto y lo añadimos al body
                const p = document.createElement("p");
                p.textContent = `Bienvenido/a ${nombre} a mi página web`;
                document.body.appendChild(p);
            } else {
                alert("No has confirmado que eres " + nombre + ", repite el proceso");
                alerta(); // volvemos a empezar
            }
        } else {
            alert("No has introducido ningún nombre, repite el proceso");
            alerta(); // volvemos a empezar
        }
    }
</script>

    Fíjate en el orden: primero se crea el párrafo, después se le pone el texto y por último se añade a la página. document.createElement("p").append(...) en una sola línea no sirve, porque append no devuelve el párrafo. En clase también probamos a crear, con el mismo texto, una lista (ul con un li) y un enlace (a): inténtalo.

  2. Saludo personalizado

    Crea ejercicio2.html con este código. Al abrir la página, te pregunta el nombre y te saluda en el párrafo.

    <!DOCTYPE html>
<html lang="es">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ejercicio 2: Saludo personalizado</title>
</head>

<body onload="saludarUsuario()">

    <h1>Ejercicio 2: Saludo personalizado</h1>

    <!-- Este párrafo está vacío al principio, pero lo llenaremos con JavaScript -->
    <p id="mensajeBienvenida"></p>

    <script>
        // Esta función se ejecutará cuando el cuerpo (body) de la página se haya cargado
        function saludarUsuario() {
            // 1. Preguntamos el nombre al usuario y lo guardamos en una variable
            const nombre = prompt("Por favor, introduce tu nombre:");

            // 2. Buscamos el elemento HTML que tiene el id="mensajeBienvenida"
            const parrafo = document.getElementById("mensajeBienvenida");

            // 3. Cambiamos el texto de ese párrafo para mostrar el saludo personalizado
            parrafo.innerText = `Hola, ${nombre}, ¡gracias por visitar nuestra web!`;
        }
    </script>

</body>

</html>

    Ahora modifícalo para que el usuario confirme si quiere continuar:

    • Antes de saludar, pregúntale con confirm si quiere ver el saludo. Si dice que no, escribe en el párrafo otro mensaje (por ejemplo, «Hasta otra»).
    • Si deja el nombre vacío o pulsa Cancelar, no le saludes: muestra un mensaje que le pida su nombre.

    Pista: recuerda que prompt devuelve null si se pulsa Cancelar, y que if (nombre) es falso tanto con null como con una cadena vacía.

  3. Comprobar la edad

    Crea ejercicio3.html con este código. Al pulsar el botón, comprueba la edad escrita en el campo.

    <!DOCTYPE html>
<html lang="es">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ejercicio 3: Comprobar edad</title>
</head>

<body>

    <h1>Ejercicio 3: Comprobar edad</h1>

    <label for="campoEdad">Introduce tu edad:</label>
    <input type="number" id="campoEdad" placeholder="Ej: 25">

    <!-- Este botón llama a la función comprobarEdad() al ser pulsado -->
    <button onclick="comprobarEdad()">Comprobar</button>

    <!-- Este div mostrará el resultado de la comprobación -->
    <div id="resultado" style="margin-top: 20px; font-weight: bold;"></div>

    <script>
        function comprobarEdad() {
            // 1. Seleccionamos el campo de entrada (input) y el div de resultado
            const inputEdad = document.getElementById("campoEdad");
            const divResultado = document.getElementById("resultado");

            // 2. Obtenemos el valor escrito en el campo y lo convertimos a número
            const edad = Number(inputEdad.value);

            // 3. Usamos un condicional para decidir qué mensaje mostrar
            if (edad >= 18) {
                // Si la edad es 18 o más...
                divResultado.innerText = "Eres mayor de edad. ¡Bienvenido/a!";
                divResultado.style.color = "green";
            } else {
                // Si la edad es menor de 18...
                divResultado.innerText = "Lo siento, no puedes acceder.";
                divResultado.style.color = "red";
            }
        }
    </script>

</body>

</html>

    Amplía la función comprobarEdad() para que haga estas comprobaciones, en este orden, y muestre cada mensaje en el div con id="resultado":

    1. Si el campo está vacío, muestra una alerta que diga que debe introducir una edad.
    2. Si la edad es mayor de 99, un mensaje que diga que debe introducir una edad menor de 99.
    3. Si es menor de 18, un mensaje que diga que es menor de edad.
    4. Si es 18 o más, un mensaje que diga que es mayor de edad.

    Pista: comprueba si está vacío antes de convertir a número, porque Number("") devuelve 0. Si quieres, prueba después a escribir las comprobaciones con switch.

  4. Cambiar el color

    Crea ejercicio4.html con este código. Cada botón llama a la misma función, pero le pasa un color diferente.

    <!DOCTYPE html>
<html lang="es">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ejercicio 4: Cambiar color</title>
</head>

<body>

    <h1>Ejercicio 4: Cambiar color de texto</h1>

    <p id="textoEjemplo">Este es un párrafo de ejemplo. Haz clic en los botones para cambiar su color.</p>

    <!-- Cada botón llama a la misma función, pero le pasa un color diferente como argumento -->
    <button onclick="cambiarColor('red')">Rojo</button>
    <button onclick="cambiarColor('green')">Verde</button>
    <button onclick="cambiarColor('blue')">Azul</button>

    <script>
        // La función acepta un parámetro, 'colorSeleccionado', que cambiará
        // dependiendo del botón que se pulse.
        function cambiarColor(colorSeleccionado) {
            // 1. Seleccionamos el párrafo por su ID
            const parrafo = document.getElementById("textoEjemplo");

            // 2. Accedemos a sus estilos (style) y cambiamos la propiedad 'color'
            parrafo.style.color = colorSeleccionado;
        }
    </script>
</body>

</html>

    Cámbialo para que haya un único botón y un campo de texto (<input type="text">) donde el usuario escriba un color en inglés (por ejemplo, orange o purple). Al pulsar el botón, la función lee el value del campo y se lo aplica al párrafo con style.color.

    Si quieres, añade más elementos (un título, otro párrafo…) y cámbiales también el color.

  5. Contador con addEventListener

    Crea ejercicio5.html con este código. Los botones suman y restan uno al número.

    <!DOCTYPE html>
<html lang="es">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ejercicio 5: Contador</title>
</head>

<body>
    <h1>Ejercicio 5: Contador</h1>

    <!-- Este h2 mostrará el número actual del contador -->
    <h2 id="numeroContador">0</h2>

    <button onclick="aumentar()">+</button>
    <button onclick="disminuir()">-</button>

    <script>
        // 1. Declaramos una variable para guardar el estado del contador.
        // La declaramos fuera de las funciones para que no se reinicie cada vez que las llamamos.
        let contador = 0;

        // 2. Seleccionamos el elemento que muestra el número para no tener que buscarlo cada vez.
        const displayContador = document.getElementById("numeroContador");

        // Función para aumentar el valor
        function aumentar() {
            contador = contador + 1; // o simplemente contador++;
            // Actualizamos el texto en la página con el nuevo valor
            displayContador.innerText = contador;
        }

        // Función para disminuir el valor
        function disminuir() {
            contador = contador - 1; // o simplemente contador--;
            // Actualizamos el texto en la página con el nuevo valor
            displayContador.innerText = contador;
        }
    </script>
</body>

</html>

    Ahora quita los atributos onclick de los botones y asocia las funciones desde el JavaScript:

    1. Selecciona el h2 por su ID (ya está hecho).
    2. Selecciona los botones por su texto: recorre todos los botones y mira cuál tiene el texto + y cuál -.
    3. Asocia a cada uno su función con addEventListener("click", ...).
    const botones = document.querySelectorAll("button");

botones.forEach((boton) => {
    if (boton.textContent === "+") {
        // este es el botón de sumar
    }
});

    Comprueba que el contador sigue funcionando igual que antes.
