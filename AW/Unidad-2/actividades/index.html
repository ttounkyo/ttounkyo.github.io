Unidad 2. Actividades

Las actividades van de menos a más: empiezas con mensajes y preguntas al usuario y terminas construyendo páginas que crean, cambian y borran elementos según lo que hace el usuario. La última es de repaso.

Cómo trabajar cada actividad:
  1. Lee primero el apartado de teoría que se indica.
  2. Crea una carpeta para la actividad y, dentro, los archivos que se piden (normalmente index.html y script.js) con un editor de código como Visual Studio Code. El código de partida se copia con el botón Copiar.
  3. Sigue el paso a paso. Para probar, abre el .html en el navegador; si algo no funciona, pulsa F12 y lee el error de la Consola. Después de cada cambio, guarda y recarga con F5.
  4. Si te atascas, en muchos pasos puedes desplegar la solución o ver la página funcionando. Intenta hacerlo antes de mirarla.
  5. Antes de entregar, marca la lista de comprobación del final. Tu avance se guarda en este navegador.
  6. Para entregar, comprime la carpeta en un .zip con el nombre ApellidoNombre_AW_Actividad2.N (por ejemplo, GarciaLucia_AW_Actividad2.3.zip).
