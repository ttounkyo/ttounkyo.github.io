1. Introducción a JavaScript

Este apartado presenta el lenguaje de programación JavaScript: para qué sirve, cómo se relaciona con el estándar ECMAScript y cómo escribir tus primeras líneas de código.

¿Qué debes saber antes?

Para seguir esta unidad necesitas:

  • Una comprensión general de Internet y la World Wide Web.
  • Saber escribir páginas sencillas en HTML.
  • Si nunca has programado, no pasa nada: empieza por los ejemplos de este apartado y del siguiente, y pruébalos en la consola.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación multiplataforma y orientado a objetos que se utiliza para hacer que las páginas web sean interactivas. Gracias a él, podemos crear desde animaciones complejas y menús desplegables hasta aplicaciones web completas que se actualizan en tiempo real.

JavaScript contiene una biblioteca estándar de objetos, como Array, Date y Math, y un conjunto básico de elementos del lenguaje como operadores, estructuras de control y declaraciones. El núcleo de JavaScript se puede extender para una variedad de propósitos completándolo con objetos adicionales:

  • JavaScript de lado del cliente (Client-Side): Es el JavaScript que se ejecuta en el navegador web. Se extiende proporcionando objetos para controlar el navegador y su Modelo de Objetos de Documento (DOM). Permite que una aplicación coloque elementos en un formulario HTML, responda a clics del ratón, valide datos y cambie dinámicamente el contenido de la página sin necesidad de recargarla.
  • JavaScript de lado del servidor (Server-Side): Versiones más avanzadas como Node.js amplían el núcleo del lenguaje con objetos relevantes para ejecutar JavaScript en un servidor. Esto permite a una aplicación comunicarse con una base de datos, gestionar usuarios, manipular archivos en el servidor y construir APIs completas.
No confundas JavaScript con Java

JavaScript y Java son similares en algunos aspectos superficiales, pero fundamentalmente diferentes. El lenguaje JavaScript se parece a Java en la sintaxis, pero no tiene su tipado estático ni su fuerte verificación de tipos. La similitud en el nombre es principalmente una decisión de marketing de la época.

JavaScript Java
Orientado a objetos basado en prototipos. La herencia es dinámica y las propiedades y métodos se pueden agregar a cualquier objeto en tiempo de ejecución. Basado en clases. Los objetos son instancias de clases y la herencia se define en la jerarquía de clases. No se pueden añadir propiedades dinámicamente.
Los tipos de datos de las variables no se declaran (tipado dinámico). Los tipos de datos de las variables deben declararse (tipado estático).
Se ejecuta principalmente en el navegador o en entornos como Node.js. Por seguridad, no puede acceder directamente al sistema de archivos del cliente. Puede ejecutarse en una máquina virtual (JVM) en cualquier sistema y tiene acceso completo a los recursos del sistema, como el disco duro.

JavaScript y la especificación ECMAScript

JavaScript está estandarizado por Ecma International. Esta versión estandarizada se denomina ECMAScript y su objetivo es asegurar que el lenguaje se comporte de la misma manera en todas las plataformas que lo soporten (navegadores, servidores, etc.). El estándar ECMAScript está documentado en la especificación ECMA-262.

Documentación y especificación

La especificación ECMA-262 es un documento técnico para los ingenieros que crean los motores de JavaScript (como V8 en Chrome o SpiderMonkey en Firefox). No está pensada para aprender a programar.

Para aprender a escribir código, debes utilizar la documentación de JavaScript, como la de MDN Web Docs, que describe el lenguaje desde la perspectiva de un programador.

Cómo empezar: la consola del navegador

Comenzar con JavaScript es fácil: todo lo que necesitas es un navegador web moderno. La Consola Web integrada en los navegadores es una herramienta increíblemente útil para experimentar.

Para abrir la Consola Web, pulsa F12 y elige la pestaña Consola. También puedes usar Ctrl+Mayús+J en Chrome y Edge, Ctrl+Mayús+K en Firefox, o Cmd+Opción+J en Chrome para Mac.

La consola es también donde aparecen los errores de tus programas: si algo no funciona, ábrela y lee el mensaje en rojo, que te dice el error y la línea.

Hola mundo en la consola

Para comenzar a escribir JavaScript, abre la Consola Web y escribe tu primer código "Hola mundo":

(function () {
  "use strict";
  /* Inicio de tu código */

  function greetMe(yourName) {
    alert("Hola " + yourName);
  }

  greetMe("Mundo");

  /* Fin de tu código */
})();

Pulsa Intro para ejecutarlo. Si quieres escribir varias líneas sin ejecutarlas todavía, usa Mayús+Intro para saltar de línea.

La primera vez que pegues código en la consola de Chrome o Edge, puede que te pida escribir allow pasting (o «permitir pegar») antes de dejarte pegar. Es una protección contra estafas: pega solo código que entiendas.
"use strict" y las IIFE

La estructura (function () { ... })(); se llama IIFE (Immediately Invoked Function Expression): es una función que se ejecuta nada más definirla. En la consola es útil porque:

  • Las variables quedan dentro de la función y no interfieren con otras partes de la página.
  • Puedes volver a ejecutar el mismo código sin el error «la variable ya está declarada».

"use strict"; activa el modo estricto, que convierte en errores algunos descuidos de principiante (por ejemplo, usar una variable sin declararla). En tus archivos .js no necesitas la IIFE: basta con declarar las variables con let y const.

Dónde se escribe el código: la etiqueta script

La consola sirve para probar. Para que una página web tenga su JavaScript, el código se escribe en un archivo aparte (por ejemplo, script.js) y se enlaza desde el HTML con la etiqueta <script>, justo antes de cerrar el <body>. Así, cuando el código se ejecuta, los elementos de la página ya existen.

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi primera página con JavaScript</title>
</head>
<body>
    <h1 id="titulo">Hola</h1>

    <!-- El script, al final del body -->
    <script src="script.js"></script>
</body>
</html>
// script.js
console.log("El script se ha cargado");
document.getElementById("titulo").textContent = "Hola desde JavaScript";

Para probarlo, guarda los dos archivos en la misma carpeta y abre el .html con el navegador (doble clic o arrastrándolo a una pestaña). Si cambias el código, guarda y recarga la página con F5.

También puedes escribir el código dentro de la propia etiqueta: <script> ... </script>. Lo que no funciona es hacer las dos cosas a la vez: si la etiqueta tiene src, el navegador ignora el código que haya dentro.

Mostrar mensajes y pedir datos

Para tus primeros programas usarás estas cuatro funciones del navegador:

Función Qué hace Qué devuelve
console.log("texto") Escribe en la consola. Es la forma más cómoda de ver el valor de una variable mientras programas. Nada
alert("texto") Muestra una ventana con un mensaje y un botón Aceptar. Nada
prompt("pregunta") Muestra una ventana con una pregunta y un cuadro para escribir. Lo que escribe el usuario, siempre como texto. Si pulsa Cancelar, devuelve null.
confirm("pregunta") Muestra una pregunta con los botones Aceptar y Cancelar. true si pulsa Aceptar y false si pulsa Cancelar. 
const nombre = prompt("¿Cómo te llamas?");
const edad = Number(prompt("¿Cuántos años tienes?")); // prompt devuelve texto: lo pasamos a número
console.log(nombre, edad);

if (confirm("¿Quieres ver un saludo?")) {
  alert(`Hola, ${nombre}`);
}

2. Conceptos básicos

JavaScript está influenciado sobre todo por la sintaxis de Java, C y C++, pero también ha sido influenciado por Awk, Perl y Python.

Distingue mayúsculas y minúsculas

JavaScript distingue entre mayúsculas y minúsculas (es case-sensitive) y utiliza el conjunto de caracteres Unicode. Por ejemplo, la palabra Früh (que significa "temprano" en alemán) se podría usar como el nombre de una variable, pero no sería la misma que früh.

let Früh = "foobar";
let früh = "another value";
console.log(Früh); // Muestra "foobar"

En JavaScript, las instrucciones se denominan declaraciones y están separadas por un punto y coma (;). Aunque no es estrictamente necesario si cada declaración está en una línea nueva, se considera una buena práctica incluirlo siempre para evitar errores inesperados.

Comentarios

La sintaxis de los comentarios es la misma que en C++ y en muchos otros lenguajes. Los comentarios se comportan como espacios en blanco y se descartan durante la ejecución del script.

// Este es un comentario de una sola línea.

/*
  Este es un comentario
  más largo, que ocupa
  varias líneas.
*/

/* No puedes anidar /* comentarios de bloque */ SyntaxError */

Declarar variables: let, const y var

JavaScript tiene tres tipos de declaraciones de variables, cada una con un comportamiento diferente en cuanto a su ámbito (scope):

  • let: declara una variable cuyo valor puede cambiar. Tiene ámbito de bloque (solo existe dentro de las llaves {} donde se declara). Puedes darle un valor al declararla o más tarde.
  • const: declara una constante: su valor no se puede reasignar. También tiene ámbito de bloque y hay que darle valor en el momento de declararla.
  • var: la forma antigua (anterior a 2015). Tiene ámbito de función y se comporta de forma extraña (lo verás más abajo). Hoy no se usa en código nuevo, pero la encontrarás en ejemplos antiguos de Internet.
Qué usar: declara con const por defecto y cambia a let solo si el valor va a cambiar (un contador, un total que se va acumulando…). No uses var.
const nombre = "Ana"; // no va a cambiar
let puntos = 0;       // va a cambiar
puntos = puntos + 10; // correcto
nombre = "Luis";      // TypeError: Assignment to constant variable.

Variables

Utiliza variables como nombres simbólicos para valores en tu aplicación. Un identificador de JavaScript debe comenzar con una letra, un guión bajo (_) o un signo de dólar ($). Los siguientes caracteres también pueden ser dígitos (0-9).

¡Cuidado con las variables sin declarar!

Si asignas un valor a una variable sin haberla declarado antes con var, let o const (por ejemplo, x = 42;), JavaScript crea una variable global no declarada. Esto se desaconseja totalmente porque puede provocar comportamientos inesperados y errores difíciles de depurar.

Ámbito de variables: var y let

Cuando declaras una variable fuera de cualquier función, se denomina variable global. Cuando la declaras dentro de una función, es una variable local.

La principal diferencia entre var y let es su ámbito:

  • var tiene ámbito de función. Esto significa que si declaras una variable con var dentro de un bloque (como un if), esa variable será accesible en toda la función que contiene el bloque. 
if (true) {
  var x = 5;
}
console.log(x); // Muestra 5, porque 'x' es accesible fuera del bloque if.
  • let (y const) tienen ámbito de bloque. La variable solo existe dentro del bloque en el que fue declarada (las llaves {}).
if (true) {
  let y = 5;
}
console.log(y); // ReferenceError: y is not defined

Elevación de variables (hoisting)

Otro concepto inusual de JavaScript es que puedes hacer referencia a una variable declarada con var antes de su declaración sin obtener una excepción. Este concepto se conoce como hoisting (elevación).

Las declaraciones de variables con var son "elevadas" al principio de su ámbito, pero su inicialización no. Por lo tanto, la variable existe pero su valor es undefined hasta que el código llega a la línea donde se le asigna un valor.

console.log(myVar); // Muestra "undefined", no un error.
var myVar = "my value";
console.log(myVar); // Muestra "my value".
Hoisting con let y const

let y const también son elevadas, pero no se inicializan. Acceder a ellas antes de su declaración resulta en un ReferenceError porque entran en una "zona muerta temporal" (Temporal Dead Zone o TDZ).

Constantes

Puedes crear una constante de solo lectura con la palabra clave const. Una constante no puede cambiar su valor a través de la reasignación.

const PI = 3.14;
PI = 3; // TypeError: Assignment to constant variable.
Importante: const no hace que el valor sea inmutable

Si una constante es un objeto o un arreglo (Array), sus propiedades o elementos sí pueden ser modificados. const solo protege la referencia, no el contenido. 

const MY_OBJECT = { key: "value" };
MY_OBJECT.key = "otherValue"; // Esto es válido.

const MY_ARRAY = ["HTML", "CSS"];
MY_ARRAY.push("JAVASCRIPT"); // Esto también es válido.

Estructuras y tipos de datos

El último estándar ECMAScript define ocho tipos de datos:

Siete tipos de datos primitivos
Booleano true y false.
null Una palabra clave especial que denota un valor nulo.
undefined El valor de una variable a la que todavía no se ha dado valor.
Number Un número entero o con coma flotante (ej: 42, 3.14).
BigInt Un número entero con precisión arbitraria (ej: 9007199254740992n).
String Una secuencia de caracteres (ej: "Hola").
Symbol Un tipo de dato cuyas instancias son únicas e inmutables.
Y Object, que es el único tipo no primitivo.

Conversión de tipos de datos

JavaScript es un lenguaje de tipado dinámico. Esto significa que no tienes que especificar el tipo de dato de una variable al declararla, y los tipos se convierten automáticamente según sea necesario. 

let answer = 42;      // answer es un Number
answer = "Gracias..."; // ahora answer es un String, sin error.

En expresiones que involucran valores numéricos y de cadena con el operador +, JavaScript convierte los números a cadenas. Con otros operadores, intenta convertir las cadenas a números.

"37" + 7; // "377" (concatenación)
"37" - 7; // 30 (resta numérica)

Para no depender de estas conversiones automáticas, convierte tú el valor: Number("37") devuelve el número 37 y String(37) el texto "37". Es lo que tienes que hacer con lo que devuelve prompt o el value de un campo de formulario, que siempre es texto.

Literales

Los literales representan valores fijos en JavaScript. Los más comunes son:

  • Literales de Arreglo (Array): Una lista de valores entre corchetes []. 
    const coffees = ["French Roast", "Colombian", "Kona"];
  • Literales Booleanos (Boolean): true y false.
  • Literales Numéricos (Number): 117, -3.14.
  • Literales de Objeto (Object): Una lista de pares clave-valor entre llaves {}. 
    const car = {
  myCar: "Saturn",
  getCar: "Honda",
  special: "Toyota"
};
  • Literales de Cadena (String): Caracteres entre comillas simples ('), dobles (") o acentos graves (`).

Plantillas literales (template literals)

Introducidas en ES2015, las plantillas literales usan acentos graves (`) y permiten:

  • Cadenas multilínea (Multiline String): Escribir texto en varias líneas de forma natural.
  • Interpolación de expresiones (Expression Interpolation): Incrustar variables y expresiones dentro de la cadena usando la sintaxis ${...}.
const name = "Bob";
const time = "hoy";
const greeting = `Hola ${name}, ¿cómo estás ${time}?`;
console.log(greeting); // Muestra "Hola Bob, ¿cómo estás hoy?"

Funciones

Una función es un bloque de código con nombre que puedes ejecutar (llamar) tantas veces como quieras. Puede recibir datos (parámetros) y devolver un resultado con return. Las usarás en todas las actividades: casi siempre, un botón llama a una función.

// Declarar la función
function sumar(a, b) {
  return a + b;
}

// Llamarla
const total = sumar(2, 3);
console.log(total); // 5

// Función flecha (arrow function): otra forma más corta de escribir funciones
const doble = (n) => n * 2;
console.log(doble(4)); // 8

Las variables declaradas dentro de una función solo existen dentro de ella. Si necesitas que un valor se conserve entre una llamada y otra (por ejemplo, un contador), declara la variable fuera de la función.

3. Operadores

JavaScript tiene un amplio conjunto de operadores para realizar asignaciones, comparaciones, operaciones aritméticas y mucho más. Esta sección describe los operadores más importantes y su precedencia.

Operadores de asignación

Un operador de asignación asigna un valor a su operando izquierdo. El más simple es la asignación (=), que no hay que confundir con la comparación (===). Además, existen operadores compuestos que son una abreviatura de operaciones comunes.

Nombre Operador abreviado Significado
Asignación x = y x = y
Asignación de adición x += y x = x + y
Asignación de resta x -= y x = x - y
Asignación de multiplicación x *= y x = x * y
Asignación de división x /= y x = x / y
Desestructuración (destructuring)

Para asignaciones más complejas, la sintaxis de desestructuración permite extraer datos de arreglos u objetos de una forma muy concisa.

const foo = ["uno", "dos", "tres"];

// Con desestructuración
const [uno, dos, tres] = foo;

console.log(uno); // "uno"

Operadores de comparación

Un operador de comparación compara sus operandos y devuelve un valor lógico (true o false).

Operador Descripción Ejemplo
Igual (==) Compara si los operandos son iguales, realizando conversión de tipo. "3" == 3 // true
No es igual (!=) Compara si los operandos no son iguales, realizando conversión de tipo. "3" != 4 // true
Estrictamente igual (===) Compara si los operandos son iguales y del mismo tipo, sin conversión de tipo. "3" === 3 // false
Desigualdad estricta (!==) Compara si los operandos no son iguales o son de diferente tipo. "3" !== 3 // true
Mayor que (>) Compara si el operando izquierdo es mayor que el derecho. 4 > 3 // true
Menor que (<) Compara si el operando izquierdo es menor que el derecho. 3 < 4 // true
Mayor o igual (>=) Compara si el operando izquierdo es mayor o igual que el derecho. 18 >= 18 // true
Menor o igual (<=) Compara si el operando izquierdo es menor o igual que el derecho. 17 <= 18 // true
Buena práctica: usa siempre === y !==

La comparación estricta (===) evita errores sutiles causados por la conversión automática de tipos. Con == pasan cosas como 0 == "" → true o "1" == 1 → true. Es la forma recomendada y más segura de comparar valores en JavaScript.

Si comparas lo que devuelve prompt o un campo de formulario con un número, convierte antes el texto con Number(): Number("18") === 18 → true.

Operadores aritméticos

Toman valores numéricos como operandos y devuelven un solo valor numérico. Los estándar son +, -, *, /. Además:

Operador Descripción Ejemplo
Resto (%) Devuelve el resto entero de una división. 12 % 5 // devuelve 2
Incremento (++) Agrega uno a su operando. let x = 3; x++; // ahora x es 4
Decremento (--) Resta uno de su operando. let x = 3; x--; // ahora x es 2
Exponenciación (**) Calcula la base a la potencia del exponente. 2 ** 3 // devuelve 8

Operadores lógicos

Se utilizan normalmente con valores booleanos y devuelven un valor booleano. Sin embargo, && y || pueden devolver el valor de uno de los operandos.

Operador Uso Descripción
AND lógico (&&) expr1 && expr2 Devuelve expr1 si se puede convertir a false; de lo contrario, devuelve expr2.
OR lógico (||) expr1 || expr2 Devuelve expr1 si se puede convertir a true; de lo contrario, devuelve expr2.
NOT lógico (!) !expr Devuelve false si su operando se puede convertir a true; de lo contrario, devuelve true.
Evaluación de cortocircuito (short-circuiting)

Las expresiones lógicas se evalúan de izquierda a derecha y se detienen tan pronto como se conoce el resultado final. Esto es muy útil para establecer valores por defecto o evitar errores.

// Si `user` es null, `getName()` nunca se ejecuta, evitando un error.
const name = user && user.getName();

// Si `config.port` no está definido, se usa 8080 como valor por defecto.
const port = config.port || 8080;

// Ojo: || también descarta 0 y "". Si esos valores son válidos, usa ??,
// que solo pone el valor por defecto si es null o undefined.
const intentos = config.intentos ?? 3;

Operador condicional (ternario)

Es el único operador de JavaScript que toma tres operandos. Es una forma compacta de escribir una declaración if...else.

La sintaxis es: condición ? valorSiTrue : valorSiFalse

const age = 20;
const status = age >= 18 ? "adulto" : "menor";

console.log(status); // "adulto"

Otros operadores útiles

Operador Descripción Ejemplo
Operador de cadena (+) Concatena dos cadenas. "hola " + "mundo" // "hola mundo"
typeof Devuelve una cadena que indica el tipo del operando. typeof 42 // "number"
instanceof Devuelve true si un objeto es una instancia de un tipo de objeto específico. new Date() instanceof Date // true
in Devuelve true si la propiedad especificada está en el objeto. 'make' in mycar // true
delete Elimina una propiedad de un objeto. delete mycar.make;
Operadores bit a bit (bitwise)

JavaScript también incluye operadores que trabajan directamente a nivel de bits (ceros y unos) de un número, como & (AND), | (OR), ^ (XOR), ~ (NOT), y operadores de desplazamiento como << y >>. Aunque son menos comunes en el desarrollo web del día a día, son fundamentales en operaciones de bajo nivel, criptografía o gráficos.

4. Expresiones

¿Qué es una expresión?

Una expresión es cualquier unidad de código válida que, al ser evaluada por el intérprete de JavaScript, se resuelve en un valor. Es la idea más fundamental en el lenguaje.

Toda expresión sintácticamente válida se resuelve en algún valor, pero conceptualmente, hay dos tipos de expresiones:

Con efectos secundarios

Son expresiones que, además de resolverse en un valor, modifican el estado del programa, como asignar un valor a una variable.

// Esta expresión asigna 7 a 'x'.
// El "efecto secundario" es el cambio en la variable 'x'.
// La expresión completa se resuelve en el valor 7.
x = 7;
Que solo evalúan

Son expresiones que simplemente calculan un valor sin modificar el estado del programa.

// Esta expresión usa el operador '+' para sumar 3 y 4.
// No modifica ninguna variable.
// La expresión se resuelve en el valor 7.
3 + 4;

Categorías de expresiones

  • Aritméticas: Se evalúa como un número (ej. 3.14159). Generalmente usa operadores aritméticos.
  • Cadenas: Se evalúa como una cadena de caracteres (ej. "Fred"). Generalmente usa operadores de cadena.
  • Lógicas: Se evalúan como true o false. A menudo implica operadores lógicos.
  • Expresiones primarias: Palabras clave básicas y expresiones generales en JavaScript.
  • Expresiones del lado izquierdo: Los valores del lado izquierdo son el destino de una asignación.

Expresiones primarias

La palabra clave this

Utiliza la palabra clave this para hacer referencia al objeto actual. En general, this se refiere al objeto que está ejecutando el método actual. El valor de this se determina por cómo se llama a la función.

Supongamos que una función llamada validate valida la propiedad value de un objeto:

function validate(obj, lowval, hival) {
  // 'obj' es el objeto que recibe la función.
  if (obj.value < lowval || obj.value > hival) {
    console.log("¡Valor no válido!");
  }
}

Puedes llamar a validate en el controlador de eventos onChange de un elemento de formulario, utilizando this para pasar el propio elemento de formulario a la función:

<p>Escribe un número entre 18 y 99:</p>
<!-- Aquí, 'this' se refiere al propio elemento 'input' -->
<input type="text" name="age" size="3" onChange="validate(this, 18, 99);" />

Operador de agrupación ()

El operador de agrupación () controla la precedencia (el orden) de la evaluación en las expresiones. Por ejemplo, puedes forzar que una suma se realice antes que una multiplicación.

let a = 1 + 2 * 3; // a es 7 (la multiplicación es primero)
let b = (1 + 2) * 3; // b es 9 (los paréntesis fuerzan la suma primero)

Expresiones del lado izquierdo

Los valores a la izquierda de un operador de asignación son el destino de esa asignación.

Operador new

Puedes utilizar el operador new para crear una instancia de un tipo de objeto, ya sea uno definido por el usuario (una clase) o uno de los tipos de objeto integrados de JavaScript.

// 'new Date()' crea una nueva instancia del objeto 'Date'
const hoy = new Date();

// 'new Array()' crea una nueva instancia de 'Array'
const miArray = new Array('a', 'b', 'c');

Palabra clave super

La palabra clave super se utiliza dentro de las clases para llamar a funciones del objeto padre (la clase de la que hereda). Su uso más común es para llamar al constructor de la clase padre.

class Animal {
  constructor(nombre) {
    this.nombre = nombre;
  }
}

class Perro extends Animal {
  constructor(nombre, raza) {
    // 'super(nombre)' llama al constructor de la clase padre (Animal)
    super(nombre);
    this.raza = raza;
  }
}

5. Control de flujo y errores

JavaScript admite un compacto conjunto de declaraciones, específicamente declaraciones de control de flujo, que puedes utilizar para incorporar una gran cantidad de interactividad en tu aplicación.

Declaración de bloque {...}

La declaración más básica es una declaración de bloque, que se utiliza para agrupar una o más instrucciones. El bloque está delimitado por un par de llaves y se usa comúnmente con declaraciones de control de flujo como if, for o while. 

let x = 0;
while (x < 10) {
  x++; // Este es el bloque de código que se ejecuta en cada iteración.
}
Ámbito de bloque: var y let

En versiones antiguas de JavaScript (antes de ECMAScript 2015), las declaraciones de bloque no creaban un nuevo ámbito. Una variable declarada con var dentro de un bloque era accesible en toda la función. A partir de ES2015, las variables declaradas con let y const tienen ámbito de bloque, lo que significa que solo existen dentro del bloque en el que fueron declaradas.

Condicionales

Una expresión condicional es un conjunto de instrucciones que se ejecutarán si una condición especificada es verdadera. JavaScript admite dos expresiones condicionales: if...else y switch.

Expresión if...else

Utiliza la expresión if para ejecutar una instrucción si una condición lógica es true. Utiliza la cláusula opcional else para ejecutar una instrucción si la condición es false. 

if (condition) {
  // Código a ejecutar si la condición es verdadera.
} else {
  // Código a ejecutar si la condición es falsa.
}

También puedes anidar condiciones usando else if:

if (condition_1) {
  statement_1;
} else if (condition_2) {
  statement_2;
} else {
  statement_last;
}
Valores "Falsy" en JavaScript

En un contexto booleano, los siguientes valores se evalúan siempre como false:

false undefined null
0 NaN "" (cadena vacía)

Todos los demás valores, incluidos todos los objetos y arreglos (incluso si están vacíos), se evalúan como true. Por eso if (nombre) es falso tanto si prompt devuelve una cadena vacía como si devuelve null (el usuario pulsó Cancelar).

Declaración switch

Una instrucción switch permite que un programa evalúe una expresión e intente hacer coincidir el valor de la expresión con una etiqueta case. Si la encuentra, el programa ejecuta la declaración asociada. La comparación es estricta (como ===): case 18 no coincide con el texto "18".

const fruittype = "Apples";

switch (fruittype) {
  case "Oranges":
    console.log("Las naranjas cuestan 0.59€ el kilo.");
    break; // 'break' evita que el código continúe al siguiente 'case'.
  case "Apples":
    console.log("Las manzanas cuestan 0.32€ el kilo.");
    break;
  case "Bananas":
    console.log("Los plátanos cuestan 0.48€ el kilo.");
    break;
  default: // Se ejecuta si ningún 'case' coincide.
    console.log(`Lo sentimos, no tenemos ${fruittype}.`);
}

Manejo de excepciones

Puedes lanzar excepciones usando la instrucción throw y manejarlas usando las declaraciones try...catch...finally.

Expresión throw

Utiliza la expresión throw para lanzar una excepción. Puedes lanzar cualquier expresión, no solo objetos de error.

// Crea un objeto de error personalizado
function UserException(message) {
  this.message = message;
  this.name = "UserException";
}

// Lanza una instancia del nuevo tipo de error
throw new UserException("Valor muy alto");

Declaración try...catch...finally

La declaración try...catch marca un bloque de código para "intentar" (try) y especifica una respuesta en caso de que se produzca una excepción (catch). El bloque finally es opcional y se ejecuta siempre, haya o no una excepción.

function getMonthName(mo) {
  mo = mo - 1; // Ajusta el número de mes para el índice del arreglo
  let months = ["Ene", "Feb", "Mar", "Abr", "May", "Jun", "Jul", "Ago", "Sep", "Oct", "Nov", "Dic"];
  if (months[mo]) {
    return months[mo];
  } else {
    throw "InvalidMonthNo"; // Lanza una excepción si el mes no es válido
  }
}

let monthName; // la declaramos fuera para poder usarla en try y en catch

try {
  // Intentamos ejecutar este código
  const myMonth = 15;
  monthName = getMonthName(myMonth);
} catch (e) {
  // Si ocurre una excepción en el bloque 'try', se ejecuta este bloque
  monthName = "unknown";
  console.error("Error capturado: ", e); // Manejamos el error
} finally {
  // Este bloque se ejecuta siempre, con o sin error.
  console.log("Proceso finalizado.");
}
El bloque finally

El bloque finally es ideal para tareas de "limpieza", como cerrar una conexión a una base de datos o un archivo, ya que garantiza que ese código se ejecutará sin importar si la operación principal tuvo éxito o falló.

Utilizar objetos Error

Para un manejo de errores más robusto, es recomendable lanzar objetos Error. Estos objetos tienen propiedades estándar como name y message que proporcionan información más detallada sobre el error.

function doSomethingErrorProne() {
  if (ourCodeMakesAMistake()) {
    throw new Error('Este es un mensaje de error específico.');
  } else {
    // ...
  }
}

try {
  doSomethingErrorProne();
} catch (e) {
  console.error(e.name);    // Muestra: 'Error'
  console.error(e.message); // Muestra: 'Este es un mensaje de error específico.'
}

6. Bucles

Los bucles ofrecen una forma rápida y sencilla de hacer algo repetidamente. Este apartado presenta las diferentes declaraciones de iteración disponibles en JavaScript, explicando no solo cómo funcionan, sino cuándo es mejor usar cada una.

Tipo de Bucle Cuándo usarlo
for Cuando sabes de antemano cuántas veces quieres que se repita el bucle. Ideal para contar.
while Cuando quieres que el bucle se repita mientras una condición sea verdadera, pero no sabes cuántas veces ocurrirá.
do...while Similar a while, pero garantiza que el bloque de código se ejecute al menos una vez.
for...in Para iterar sobre las claves (propiedades) de un objeto.
for...of Para iterar sobre los valores de un objeto iterable (como arreglos, cadenas, Map, Set).

Bucles contadores: el bucle for

El bucle for se repite hasta que una condición especificada se evalúe como false. Es el bucle más común cuando se necesita un contador.

Su sintaxis se compone de tres partes:

  1. Inicialización: Se ejecuta una sola vez, al principio. Aquí se suele declarar e inicializar la variable contadora.
  2. Condición: Se evalúa antes de cada iteración. Si es true, el bucle continúa. Si es false, el bucle termina.
  3. Expresión de actualización: Se ejecuta al final de cada iteración. Aquí se suele incrementar o decrementar el contador.
// for ([inicialización]; [condición]; [actualización])

for (let i = 0; i < 5; i++) {
  // Se ejecuta 5 veces, con valores de i desde 0 hasta 4.
  console.log("Camina un paso hacia el este. Paso número: " + (i + 1));
}

Bucles condicionales: while y do...while

Declaración while

Una declaración while ejecuta sus instrucciones siempre que una condición especificada se evalúe como true. La condición se comprueba antes de cada iteración.

let n = 0;
while (n < 3) {
  n++;
  console.log("El valor de n es: " + n);
}
// Salida:
// El valor de n es: 1
// El valor de n es: 2
// El valor de n es: 3
¡Cuidado con los bucles infinitos!

Asegúrate de que la condición en un bucle while eventualmente se convierta en false. De lo contrario, el bucle nunca terminará y bloqueará tu programa.

Declaración do...while

La instrucción do...while es casi idéntica a while, pero con una diferencia crucial: la condición se comprueba después de cada iteración. Esto garantiza que el bloque de código se ejecute al menos una vez.

let i = 5;
do {
  console.log("El valor de i es: " + i);
  i++;
} while (i < 5);

// Salida:
// El valor de i es: 5
// (El bucle se ejecuta una vez, aunque la condición inicial '5 < 5' es falsa)

Bucles iteradores: for...in y for...of

Estos bucles fueron diseñados para iterar sobre estructuras de datos de una forma más sencilla y directa que un bucle for tradicional.

Declaración for...in

La instrucción for...in itera sobre todas las propiedades enumerables (claves) de un objeto.

const user = {
  name: 'Juan',
  age: 30,
  city: 'Madrid'
};

for (const key in user) {
  console.log(`La clave es: ${key}, y su valor es: ${user[key]}`);
}
// Salida:
// La clave es: name, y su valor es: Juan
// La clave es: age, y su valor es: 30
// La clave es: city, y su valor es: Madrid
No uses for...in para arreglos

Aunque técnicamente funciona, no se recomienda usar for...in para iterar sobre arreglos. Recorre las claves como texto ("0", "1"…) y puede recorrer propiedades inesperadas si el prototipo del arreglo ha sido modificado. Para arreglos usa for o for...of.

Declaración for...of

Introducida en ES2015, la declaración for...of crea un bucle que itera sobre los valores de objetos iterables (como Array, String, Map, Set, etc.).

Este es el método moderno y recomendado para iterar sobre los valores de un arreglo.

const arr = [3, 5, 7];

for (const value of arr) {
  console.log(value); // Muestra 3, luego 5, luego 7
}

Control del flujo de un bucle

A veces necesitas alterar el comportamiento normal de un bucle, ya sea para salir de él prematuramente o para saltar una iteración.

Declaración break

Usa la instrucción break para terminar un bucle por completo y transferir el control a la siguiente instrucción después del bucle.

for (let i = 0; i < 10; i++) {
  if (i === 5) {
    break; // El bucle se detiene aquí
  }
  console.log(i); // Se mostrarán los números del 0 al 4
}
console.log("Bucle finalizado.");

Declaración continue

La instrucción continue se usa para saltar la iteración actual y continuar con la siguiente iteración del bucle.

for (let i = 0; i < 5; i++) {
  if (i === 2) {
    continue; // Salta la iteración cuando i es 2
  }
  console.log(i); // Se mostrarán los números 0, 1, 3, 4
}

7. El árbol DOM

¿Qué es el DOM?

El Document Object Model (DOM) es la representación en forma de árbol de tu página web. Imagínalo como un árbol genealógico de tu HTML.

El objeto document es nuestro punto de entrada para interactuar con cualquier elemento de la página. Nos proporciona una serie de métodos poderosos para encontrar, crear y modificar los nodos del árbol DOM.

Visualizando el árbol DOM

document (📄)
└── html (🌐)
    ├── head (📝)
    │   └── title
    └── body (👤)
        ├── h1
        ├── p
        └── div (📦)
            └── ul (📋)
                ├── li (✅)
                └── li (✅)

Piénsalo así:

Tu página web es como una casa:

  • document = La casa completa
  • body = La sala de estar
  • div, p, h1 = Los muebles
  • JavaScript = Tú, moviendo los muebles

Encontrar elementos (selección)

Primero necesitamos "agarrar" los elementos para poder trabajar con ellos.

getElementById('id')

Búsqueda por ID: Encuentra UN elemento por su ID único.

<div id="caja">Contenido</div>

Recuerda: el ID debe ser único en toda la página.

querySelector('selector')

primerParrafo.textContent = '¡Soy el primero!';
Puedes usar: '.clase', '#id', 'p', 'div.clase'

querySelectorAll('selector')

Todos los que coincidan: Encuentra TODOS los elementos.

<ul>
  <li>Tarea 1</li>
  <li>Tarea 2</li>
  <li>Tarea 3</li>
</ul>

tareas.forEach((tarea, indice) => {
  tarea.textContent = `Tarea ${indice + 1} - Completada`;
});

No solo podemos modificar elementos existentes, ¡también crear nuevos!

Añadir y quitar elementos

8. Eventos

¿Qué es un evento?

Los eventos son "cosas que pasan" en el sistema que estás programando. El sistema se encarga de producir una señal cuando un evento ocurre y proporciona un mecanismo para que una acción (tu código) se ejecute automáticamente. En la web, los eventos se lanzan dentro de la ventana del navegador y están asociados a un elemento específico.

Algunos ejemplos de eventos son:

  • El usuario hace clic o pasa el ratón por encima de un elemento.
  • El usuario presiona una tecla del teclado.
  • Una página web termina de cargarse.
  • Un formulario es enviado.
  • Un vídeo se reproduce, se pausa o se termina.

Para reaccionar a un evento, le asociamos un manejador de eventos (o "event handler"), que es una función de JavaScript que se ejecuta cuando el evento ocurre.

El método moderno: addEventListener()

El método addEventListener() es la forma recomendada para registrar un manejador de eventos. Permite añadir múltiples manejadores a un mismo evento.

Su sintaxis básica recibe dos parámetros: el nombre del evento y la función a ejecutar.

const btn = document.querySelector("button");

function random(number) {
  return Math.floor(Math.random() * (number + 1));
}

// Se puede pasar una función anónima (arrow function)
btn.addEventListener("click", () => {
  const rndCol = `rgb(${random(255)}, ${random(255)}, ${random(255)})`;
  document.body.style.backgroundColor = rndCol;
});

// O se puede pasar una función con nombre
function changeBackground() {
  const rndCol = `rgb(${random(255)}, ${random(255)}, ${random(255)})`;
  document.body.style.backgroundColor = rndCol;
}
btn.addEventListener("click", changeBackground);

Quitar un manejador: removeEventListener()

Si has agregado un manejador, también puedes eliminarlo con removeEventListener(). Para que funcione, debes pasarle exactamente la misma función con nombre que usaste para añadirlo.

// Para quitar el manejador, la función debe tener un nombre.
btn.removeEventListener("click", changeBackground);

Otros mecanismos (antiguos y desaconsejados)

Propiedades como onclick

Los elementos del DOM tienen propiedades como onclick, onmouseover, etc., a las que puedes asignar una función. La principal desventaja es que solo puedes asignar un manejador por evento. Si asignas un segundo, el primero se sobrescribe.

btn.onclick = function1;
btn.onclick = function2; // ¡`function1` ha sido eliminada y nunca se ejecutará!
Manejadores en el propio HTML

Es posible que veas código que asigna eventos directamente en el HTML, como <button onclick="bgChange()">. Esta es una práctica obsoleta y desaconsejada porque mezcla la estructura (HTML) con el comportamiento (JavaScript), lo que dificulta enormemente el mantenimiento y la escalabilidad del código.

En las primeras actividades lo verás porque es fácil de leer, pero en tus propios programas usa addEventListener().

El objeto Event

Cuando un evento ocurre, el navegador pasa automáticamente un objeto especial a tu función manejadora. Este objeto, comúnmente llamado event, evt o e, contiene información y métodos muy útiles.

function bgChange(e) {
  // `e.target` es el elemento exacto que originó el evento (el botón).
  const rndCol = `rgb(${random(255)}, ${random(255)}, ${random(255)})`;
  e.target.style.backgroundColor = rndCol;

  // La propiedad `key` solo existe en eventos de teclado.
  if (e.key) {
    console.log(`Presionaste la tecla: ${e.key}`);
  }
}
btn.addEventListener("click", bgChange);

Evitar el comportamiento por defecto: event.preventDefault()

Algunos eventos tienen un comportamiento por defecto. Por ejemplo, al enviar un formulario, la página se recarga. Podemos detener este comportamiento con event.preventDefault() para realizar validaciones.

// form, fname, lname y para son elementos seleccionados antes (por ejemplo, con querySelector)
form.addEventListener("submit", (e) => {
  if (fname.value === "" || lname.value === "") {
    // Si algún campo está vacío, detenemos el envío del formulario.
    e.preventDefault();
    para.textContent = "¡Necesitas completar ambos campos!";
  }
});

Propagación de eventos: burbujeo y captura

Cuando un evento ocurre en un elemento anidado, el evento "viaja" a través de sus ancestros en el DOM.

Burbujeo (bubbling): de dentro hacia fuera

Por defecto, el evento se dispara primero en el elemento más interno, y luego "burbujea" hacia arriba a través de sus padres. Este comportamiento puede causar problemas si varios ancestros tienen un listener para el mismo evento. Podemos detenerlo con event.stopPropagation().

// Ejemplo: un video dentro de una caja que se oculta al hacer clic.
video.addEventListener("click", (event) => {
  // Evita que el clic en el video se propague a la caja (su padre).
  event.stopPropagation();
  video.play();
});

box.addEventListener("click", () => {
  box.classList.add("hidden");
});

Captura (capturing): de fuera hacia dentro

Existe una fase previa al burbujeo donde el evento viaja desde el document hacia abajo hasta el elemento objetivo. Se activa pasando { capture: true } a addEventListener.

Delegación de eventos

El burbujeo es la base de una técnica muy potente y eficiente. En lugar de añadir un manejador a cada uno de los 100 elementos de una lista, podemos añadir un único manejador al contenedor padre. Dentro del manejador, usamos event.target para saber qué hijo exacto fue el que originó el evento.

// HTML: <div id="container"> <div class="tile"></div> ... </div>
const container = document.querySelector("#container");

function colorAleatorio() {
  return `rgb(${random(255)}, ${random(255)}, ${random(255)})`;
}

container.addEventListener("click", (event) => {
  // `event.currentTarget` es el #container
  // `event.target` es el .tile en el que se ha hecho clic
  event.target.style.backgroundColor = colorAleatorio();
});
No solo en páginas web

Los eventos no son exclusivos de JavaScript en el navegador. La mayoría de lenguajes de programación y entornos, como Node.js, poseen algún tipo de modelo de eventos, aunque la sintaxis y el funcionamiento pueden ser diferentes.

Opciones de addEventListener

// Método recomendado (permite múltiples listeners)
element.addEventListener('click', handler, {
  capture: false,      // Fase de captura?
  once: true,          // Se ejecuta una vez
  passive: true        // Para scroll/touch mejor performance
});

// Métodos antiguos (evitar)
element.onclick = handler; // Sobrescribe listeners previos

// Remover evento
element.removeEventListener('click', handler);

Delegación con matches() y propiedades del evento

// Delegación de eventos (eficiente para múltiples elementos)
document.addEventListener('click', function(event) {
  if (event.target.matches('.boton')) {
    console.log('Has hecho clic en un botón');
  }
});

// Propiedades del evento
event.preventDefault();  // Evita comportamiento por defecto
event.stopPropagation(); // Detiene propagación
event.stopImmediatePropagation(); // Detiene otros listeners
event.target;            // Elemento que originó el evento
event.currentTarget;     // Elemento con el listener
event.type;              // Tipo de evento

Eventos personalizados

// Crear evento personalizado
const evento = new CustomEvent('micustom', {
  detail: { mensaje: 'Hola' },
  bubbles: true,
  cancelable: true
});

// Disparar evento
element.dispatchEvent(evento);

// Escuchar evento personalizado
element.addEventListener('micustom', (e) => {
  console.log(e.detail.mensaje); // "Hola"
});
