Actividad 6.5. Tienda de informática: crear las tablas

Vas a crear la base de datos de una tienda de informática con dos tablas, Fabricante y Articulos, y a cambiar su estructura con ALTER TABLE hasta dejarlas relacionadas con una clave ajena.

Lo que vas a practicar

  • CREATE DATABASE y CREATE TABLE
  • Tipos de datos: INT, VARCHAR y DECIMAL
  • Añadir columnas y la clave primaria con ALTER TABLE
  • Relacionar dos tablas con FOREIGN KEY

Antes de empezar

  • Teoría: 2. Crear y modificar tablas
  • Repasa también los tipos de datos
  • Todo se hace en los editores de esta página. Si quieres, al final lo pruebas también en phpMyAdmin.

Paso a paso

Cada editor ya tiene hechos los pasos anteriores, así que puedes empezar por cualquiera. Pulsa Ejecutar para ver qué hace tu código y Comprobar para saber si está bien. Lo que escribes se guarda en este navegador.

  1. Crea la base de datos

    En MySQL, lo primero es crear la base de datos y entrar en ella con USE. Las tablas que crees después se guardan dentro.

    CREATE DATABASE TiendaInformatica;
USE TiendaInformatica;
    En los editores de esta página ya estás dentro de una base de datos vacía, así que estas dos órdenes no cambian nada. Ponlas igualmente al principio de tu archivo .sql: en phpMyAdmin sí hacen falta.

  2. Crea la tabla Fabricante

    Crea la tabla Fabricante con dos columnas: Codigo, un número entero, y Nombre, un texto de hasta 100 caracteres. No le pongas todavía clave primaria: lo harás en el paso siguiente.

    Después de crearla, escribe DESCRIBE Fabricante; para ver cómo ha quedado.

  3. Añade la clave primaria

    La tabla ya existe, así que no hace falta borrarla: se cambia con ALTER TABLE. Haz que Codigo sea la clave primaria de Fabricante.

    Con DESCRIBE verás PRI en la columna Key.

    Para ir más allá: el nombre de un fabricante no debería quedar vacío. Puedes cambiarlo con ALTER TABLE Fabricante MODIFY Nombre VARCHAR(100) NOT NULL;

  4. Crea la tabla Articulos

    Crea la tabla Articulos con Codigo (entero y clave primaria, esta vez dentro del propio CREATE TABLE) y Nombre (texto de hasta 100 caracteres).

  5. Añade las columnas Fabricante y Precio

    Con ALTER TABLE, añade a Articulos dos columnas, en este orden:

    1. Fabricante, un número entero. Guardará el código del fabricante de cada artículo.
    2. Precio, un número decimal con dos decimales (DECIMAL(8,2)), que tiene que quedar antes de Fabricante.

    Para colocar una columna en un sitio concreto, termina el ADD con AFTER columna (detrás de esa columna) o con FIRST (la primera).

  6. Relaciona las tablas con una clave ajena

    Cada artículo es de un fabricante. Haz que la columna Fabricante de Articulos sea una clave ajena (FOREIGN KEY) que apunte a Codigo de la tabla Fabricante.

    Así, la base de datos no dejará guardar un artículo de un fabricante que no existe.

    En el DESCRIBE verás MUL en la columna Key de Fabricante: así marca MySQL una clave ajena.

  7. Comprueba que la clave ajena funciona

    Este editor ya tiene las dos tablas terminadas. Ejecuta el código tal como está: el primer INSERT funciona, pero el segundo da error. ¿Por qué? Cambia el segundo para que el artículo sea del fabricante 1 y vuelve a ejecutar.

    Ver la explicación

    No existe ningún fabricante con el código 7, y la clave ajena no deja guardar un artículo que apunte a un fabricante que no está en la tabla Fabricante. Con el código 1 (Nokia) sí funciona.

  8. Junta todo en tu archivo y pruébalo en phpMyAdmin

    Copia en un archivo de texto, en orden, las sentencias de los pasos 1 a 6 y guárdalo como ApellidoNombre_AO_Actividad6.5.sql. Puedes usar el Bloc de notas o Visual Studio Code.

    Si tienes XAMPP, pruébalo: en phpMyAdmin abre la pestaña SQL, pega todo el archivo y pulsa Continuar. A la izquierda aparecerá la base de datos TiendaInformatica con sus dos tablas.
