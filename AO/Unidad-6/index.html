Unidad 6. Bases de datos

En esta unidad vas a aprender a diseñar una base de datos (qué tablas necesita y cómo se relacionan) y a manejarla con SQL, el lenguaje con el que se crean las tablas, se guardan los datos y se hacen consultas.

Diseño de bases de datos Qué es una base de datos, el modelo entidad-relación, cómo pasar el diagrama a tablas, tipos de datos y normalización. 6 apartados SQL Crear y modificar tablas, insertar y borrar datos, y hacer consultas a una y a varias tablas. Con un editor para probarlo todo. 8 apartados Actividades 4 de diseño, 5 de SQL paso a paso con una tienda de informática y 3 de repaso. 12 actividades

Cómo trabajar esta unidad

  1. Empieza por la teoría de diseño y haz las actividades 6.1 a 6.4.
  2. Sigue con la teoría de SQL y haz las actividades 6.5 a 6.9: todas usan la misma base de datos, la de una tienda de informática.
  3. Para terminar, haz las actividades de repaso 6.10 a 6.12, que juntan todo lo de la unidad.

Qué necesitas

  • Solo el navegador. La teoría de SQL y las actividades tienen un editor donde escribes las sentencias y ves el resultado al momento, sin instalar nada. Por dentro usa SQLite, pero entiende las órdenes de MySQL que vas a aprender.
  • XAMPP con phpMyAdmin (recomendado). Para trabajar con MySQL de verdad, como en una empresa. En la teoría de SQL tienes cómo instalarlo y las bases de datos de práctica para importarlas.
  • Para los diagramas, papel y lápiz o diagrams.net (gratis, en el navegador).
