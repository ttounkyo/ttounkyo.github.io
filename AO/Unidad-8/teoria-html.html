Unidad 8. HTML: la estructura de una página web

La parte de HTML tiene 5 actividades y el proyecto final. Ver las actividades

1. ¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje de marcado que se utiliza para crear y estructurar páginas web. Organiza el contenido como títulos, párrafos, imágenes, enlaces y más.

Ejemplo básico de HTML

<!DOCTYPE html>
<html>
    <head>
        <title>Mi primera página</title>
    </head>
    <body>
        <h1>¡Hola, mundo!</h1>
        <p>Esta es mi primera página web en HTML.</p>
    </body>
</html>

Explicación del ejemplo:

  • <!DOCTYPE html> define que el documento es HTML5
  • <html> es el elemento raíz de la página
  • <head> contiene información sobre el documento
  • <title> establece el título del documento
  • <body> contiene los elementos visibles
  • <h1> define el titular de la página
  • <p> define un párrafo

HTML Tags (Etiquetas HTML)

Las etiquetas HTML se escriben entre corchetes angulares y definen los distintos elementos de una página. 

<etiqueta>Contenido</etiqueta>
  • Las etiquetas vienen en pares: <p> y </p>
  • La etiqueta de cierre incluye una barra: </nombre>

Navegadores

Los navegadores como Chrome, Firefox, Edge o Safari leen documentos HTML y los muestran en pantalla.

  • No muestran las etiquetas, pero las usan para estructurar el contenido.

La declaración <!DOCTYPE>

Esta declaración indica al navegador que se está utilizando HTML5 y debe colocarse al principio del archivo HTML.

  • Aparece una sola vez, antes de la etiqueta <html>
  • No distingue entre mayúsculas y minúsculas
  • Versión HTML5: <!DOCTYPE html>

4. Listas

Elemento Descripción Ejemplo
<ul> Lista no ordenada. <ul> <li>Elemento 1</li> <li>Elemento 2</li> </ul>
<ol> Lista ordenada. <ol type="1" start="3"> <li>Elemento 3</li> <li>Elemento 4</li> </ol>
<li> Elemento de lista. <li>Elemento de lista</li>

<dt> Elemento que representa un término dentro de una lista de definiciones. <dl><dt>HTML</dt> <dd>Lenguaje de marcado para la web.</dd> </dl>
<dd> Descripción o definición del término anterior. <dl> <dt>CSS</dt> <dd>Lenguaje para estilizar páginas web.</dd> </dl>

Listas no ordenadas (<ul>)

La etiqueta <ul> (Unordered List) se utiliza para crear listas sin un orden específico, donde cada elemento está marcado con un punto o viñeta.

<ul>
    <li>Elemento 1</li>
    <li>Elemento 2</li>
    <li>Elemento 3</li>
</ul>

Listas ordenadas (<ol>)

La etiqueta <ol> (Ordered List) crea listas numeradas o con otro tipo de ordenación. Puedes personalizar el tipo y el número de inicio:

<ol type="1" start="3">
    <li>Elemento 3</li>
    <li>Elemento 4</li>
</ol>

Tipos de numeración en listas ordenadas:

  • type="1": Números (1, 2, 3...)
  • type="A": Letras mayúsculas (A, B, C...)
  • type="a": Letras minúsculas (a, b, c...)
  • type="I": Números romanos mayúsculos (I, II, III...)
  • type="i": Números romanos minúsculos (i, ii, iii...)

Elementos de lista (<li>)

La etiqueta <li> (List Item) se usa para definir cada elemento dentro de una lista. Siempre debe estar dentro de un elemento padre <ul>, <ol> o <menu>. 

<li>Elemento de lista</li>

Listas de definiciones (<dl>)

La etiqueta <dl> (Definition List) se utiliza para crear listas de términos y sus definiciones:

<dl>
    <dt>Término</dt>
    <dd>Definición</dd>
    <dt>Otro término</dt>
    <dd>Otra definición</dd>
</dl>

Importante al formatear listas:

  • Siempre cierra cada etiqueta <li> con </li>
  • Asegúrate de que los elementos <li> estén siempre dentro de un elemento contenedor (<ul>, <ol> o <menu>)
  • Para las listas de definición, usa siempre <dt> para el término y <dd> para la definición

Ejemplo del uso de listas en HTML

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Listas en HTML</title>
</head>
<body>

    <h2>Lista no ordenada</h2>
    <ul>
        <li>Manzana</li>
        <li>Banana</li>
        <li>Cereza</li>
    </ul>

    <h2>Lista ordenada</h2>
    <ol type="A" start="2">
        <li>Segundo elemento</li>
        <li>Tercer elemento</li>
    </ol>

    <h2>Lista de definiciones</h2>
    <dl>
        <dt>HTML</dt>
        <dd>Lenguaje de marcado de hipertexto</dd>

        <dt>CSS</dt>
        <dd>Hojas de estilo en cascada</dd>

        <dt>JS</dt>
        <dd>JavaScript, lenguaje de programación para la web</dd>
    </dl>

</body>
</html>

Etiqueta <img>

La etiqueta <img> se utiliza para insertar imágenes en una página web. Es una etiqueta vacía (no tiene etiqueta de cierre) y debe incluir al menos el atributo src.

Ejemplo:

<img src="ruta/imagen.jpg" alt="Descripción de la imagen">

Atributos principales de <img>:

  • src: Especifica la ruta de la imagen. Puede ser relativa (ej: imágenes/logo.png) o absoluta (ej: https://ejemplo.com/logo.png).
  • alt: Texto alternativo que se muestra si la imagen no se puede cargar. Es importante para la accesibilidad.
  • width: Define el ancho de la imagen (en píxeles o %).
  • height: Define la altura de la imagen.
  • title: Texto que aparece al pasar el cursor por encima.

Ejemplo completo:

<img src="imagenes/perro.jpg" alt="Un perro jugando" width="300" height="200" title="Perro feliz">

Formato dentro de listas:

Puedes usar imágenes dentro de elementos de lista:

<ul>
    <li>
        <img src="iconos/sol.png" alt="Sol"> Día soleado
    </li>
    <li>
        <img src="iconos/lluvia.png" alt="Lluvia"> Día lluvioso
    </li>
</ul>

Imágenes como enlaces:

<a href="https://example.com"> <img src="boton.png" alt="Ir a ejemplo"> </a>

Importante:

  • Siempre incluir el atributo alt para accesibilidad.
  • No uses imágenes decorativas sin alt o usa alt="" si no aportan información.
  • Asegúrate de que el archivo existe en la ruta indicada.

    <img src="imagen.jpg" alt="Descripción de la imagen" width="300" height="200">

    <figure>
        <img src="imagen.jpg" alt="Descripción">
        <figcaption>Leyenda de la imagen</figcaption>

Etiqueta <a>

La etiqueta <a> (anchor) se utiliza para crear enlaces en una página web. Es una etiqueta que requiere una etiqueta de cierre y debe incluir al menos el atributo href.

Ejemplo:

<a href="https://ejemplo.com">Texto del enlace</a>

Atributos principales de <a>:

  • href: Especifica la URL de destino. Puede ser relativa (ej: contacto.html), absoluta (ej: https://ejemplo.com), anclaje interno (ej: #seccion1), o protocolos especiales (ej: mailto:, tel:).
  • target: Define dónde se abrirá el enlace (_blank, _self, _parent, _top).
  • rel: Establece la relación entre la página actual y la enlazada (ej: nofollow, noopener, noreferrer).
  • download: Indica que el enlace descargará un archivo.
  • title: Texto que aparece al pasar el cursor por encima.

Ejemplo completo:

<a href="https://ejemplo.com" target="_blank" rel="noopener noreferrer" title="Visita nuestra página">Visitar Ejemplo.com</a>

7. Tablas

Elemento Descripción Ejemplo
<table> Define una tabla en HTML. Es el contenedor principal de las filas y columnas de datos. <table>...</table>
<tr> Representa una fila de la tabla, y dentro de esta fila se agrupan las celdas de la tabla. <tr>...</tr>
<th> Define una celda de encabezado en una tabla. Usualmente se utiliza para nombrar las columnas o filas, destacando el contenido con un formato especial (negrita y centrado por defecto). <th scope="col">Nombre</th>
<td> Representa una celda de datos en una tabla. Puede incluir texto, números, imágenes, entre otros. <td colspan="2">Datos</td>
<thead> Sección de la tabla que agrupa las filas del encabezado. Normalmente se utiliza para contener las celdas de encabezado de la tabla. <thead>...</thead>
<tbody> Sección del cuerpo de la tabla que contiene las filas con los datos principales de la tabla. Es donde se muestran los registros de información. <tbody>...</tbody>
<tfoot> Sección del pie de la tabla que se usa para agrupar los pies de las columnas o para colocar totales. Se suele utilizar al final de las tablas con cálculos. <tfoot>...</tfoot>
<caption> Define el título o descripción de una tabla. Se coloca antes de las secciones <thead>, <tbody> y <tfoot>. <caption>Título de la tabla</caption>

Etiqueta <table> para crear tablas

La etiqueta <table> se utiliza para definir una tabla en HTML. Esta etiqueta contiene otras etiquetas que definen filas y celdas dentro de la tabla.

Ejemplo básico:

<table>
    <tr>
        <th>Encabezado 1</th>
        <th>Encabezado 2</th>
    </tr>
    <tr>
        <td>Dato 1</td>
        <td>Dato 2</td>
    </tr>
</table>
Encabezado 1 Encabezado 2
Dato 1 Dato 2

Atributos principales de <table>:

  • border: Define el grosor de los bordes de la tabla (en píxeles).
  • cellspacing: Define el espacio entre las celdas.
  • cellpadding: Define el espacio dentro de las celdas, entre el contenido y el borde.
  • width: Define el ancho de la tabla.

Ejemplo con bordes, espacio entre celdas y celdas con padding:

<table style="border:1px solid" cellspacing="5" cellpadding="10">
    <tr>
        <th>Encabezado 1</th>
        <th>Encabezado 2</th>
    </tr>

    </tr>

Etiqueta <tr> para filas

La etiqueta <tr> define una fila dentro de la tabla.

Ejemplo:

<tr>
        <td>Celda 1</td>
        <td>Celda 2</td>
    </tr>

Etiqueta <th> para encabezados de la tabla

La etiqueta <th> define una celda de encabezado. Los encabezados están generalmente en negrita y centrados por defecto.

Ejemplo:

<th>Encabezado</th>

Etiqueta <td> para celdas de datos

La etiqueta <td> define una celda de datos dentro de una fila. Es el contenido principal de la tabla.

Ejemplo:

<td>Dato</td>

Ejemplo completo de tabla:

<table style="border:1px solid" cellspacing="2" cellpadding="5">
    <caption>Tabla de ejemplo</caption>
    <thead>
        <tr>
            <th>Nombre</th>
            <th>Edad</th>
            <th>Ciudad</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Ana</td>
            <td>28</td>
            <td>Madrid</td>
        </tr>
        <tr>
            <td>Juan</td>
            <td>35</td>
            <td>Barcelona</td>
        </tr>
        <tr>
            <td>Pedro</td>
            <td>22</td>
            <td>Valencia</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="3">Fin de la tabla</td>
        </tr>
    </tfoot>
</table>
Tabla de ejemplo
Nombre Edad Ciudad
Ana 28 Madrid
Juan 35 Barcelona
Pedro 22 Valencia
Fin de la tabla

Notas importantes:

  • caption: Se utiliza para agregar un título a la tabla.
  • thead, tbody y tfoot: Estas etiquetas se utilizan para agrupar las secciones de la tabla (encabezado, cuerpo y pie).
  • colspan: Atributo que permite que una celda ocupe varias columnas. Ejemplo: <td colspan="2">Celda amplia</td>
  • rowspan: Atributo que permite que una celda ocupe varias filas. Ejemplo: <td rowspan="2">Celda que ocupa dos filas</td>
