Unidad 8. HTML y CSS

En esta unidad vas a crear tus propias páginas web. Con HTML escribes el contenido y su estructura (títulos, párrafos, listas, imágenes, enlaces y tablas) y con CSS decides cómo se ve (colores, fuentes, tamaños y posición).

Teoría de HTML Estructura de una página, texto, listas, imágenes, enlaces y tablas. 7 apartados Teoría de CSS Cómo se escribe una regla, propiedades más usadas, unidades y selectores. 8 apartados Actividades 5 de HTML, 5 de CSS y un proyecto final en el que creas tu propio sitio web. 11 actividades

Cómo trabajar esta unidad

  1. Empieza por la teoría de HTML y haz las actividades 8.1 a 8.5.
  2. Sigue con la teoría de CSS y haz las actividades 8.6 a 8.10.
  3. Para terminar, junta todo en el proyecto final.

Qué necesitas

  • Un editor de código, como Visual Studio Code. Escribes el código en un archivo con la extensión .html (o .css para los estilos).
  • Un navegador (Chrome, Firefox, Edge o Safari) para abrir el archivo y ver cómo queda. Cada vez que guardes un cambio, recarga la página para verlo.
