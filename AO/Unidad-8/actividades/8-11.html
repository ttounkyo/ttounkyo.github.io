Actividad 8.11. Proyecto final: tu sitio web

Vas a crear un sitio web de tres páginas enlazadas mediante un menú, con todas las etiquetas que has aprendido y una hoja de estilos externa común para todas.

Lo que vas a practicar

  • p, div, span, em y strong
  • ul, ol y li
  • a e img
  • table
  • Una hoja de estilos externa enlazada con <link>

Antes de empezar

  • Teoría: toda la teoría de HTML
  • Teoría: 1. Introducción a CSS (cómo enlazar una hoja de estilos)
  • Busca al menos tres imágenes para la galería.

Ejemplo de resultado

Este es un sitio sencillo que cumple lo que se pide. Puedes navegar por él con su menú. El tuyo puede tener el diseño que quieras.

Paso a paso

  1. Crea los archivos

    En tu carpeta crea los tres documentos HTML (index.html, pagina2.html y pagina3.html), la hoja de estilos estilos.css y una carpeta para las imágenes.

  2. Enlaza la hoja de estilos en todas las páginas

    En el head de cada una de las tres páginas añade:

    <link rel="stylesheet" href="estilos.css">

    No escribas estilos dentro de las páginas: todo el CSS va en estilos.css. Así, si cambias un color, cambia en todo el sitio a la vez.

  3. El menú

    Al principio de cada página escribe el mismo menú, con un enlace a cada una de las tres páginas:

    <div class="menu">
    <a href="index.html">Inicio</a>
    <a href="pagina2.html">Galería</a>
    <a href="pagina3.html">Tabla</a>
</div>

  4. Página 1: index.html

    • Un título y un párrafo de bienvenida.
    • Un div con una lista ordenada y otra no ordenada.
    • Enlaces, y texto en cursiva (em) y en negrita (strong).

  5. Página 2: pagina2.html

    • Un título y un párrafo.
    • Una galería de al menos tres imágenes, dentro de un <div class="galeria">.

  6. Página 3: pagina3.html

    • Un título y un párrafo.
    • Una tabla con al menos 3 columnas y 2 filas.

  7. Dale estilo

    En estilos.css da estilo al menú, las listas, las imágenes de la galería, la tabla y todo lo que quieras. Usa span para dar estilo a alguna palabra concreta.
