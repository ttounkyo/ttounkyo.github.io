Actividad 8.8. Estilos para una tabla

Tienes una tabla en la que cada fila lleva el nombre de un color. Dale estilo de la mejor manera que se te ocurra y explica tu código con comentarios.

Lo que vas a practicar

  • Añadir clases e ID al HTML para poder darles estilo
  • color, background-color, border y padding
  • Comentarios en CSS (/* ... */)

Antes de empezar

  • Teoría: 3. Propiedades (color, fondo, espaciado y borde)
  • Teoría: 6. Selectores de clase y 7. Selectores de ID

Paso a paso

  1. Crea el documento con el código

    Crea el archivo index.html, pulsa Copiar y pega el código completo. Añade una etiqueta <style></style> dentro del head.

    <!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ejercicio de CSS</title>
  </head>
  <body>
    <table border="1">
      <tr>
        <td>teal</td>
        <td>teal</td>
        <td>teal</td>
      </tr>
      <tr>
        <td>red</td>
        <td>red</td>
        <td>red</td>
      </tr>
      <tr>
        <td>blue</td>
        <td>blue</td>
        <td>blue</td>
      </tr>
      <tr>
        <td>orange</td>
        <td>orange</td>
        <td>orange</td>
      </tr>
      <tr>
        <td>purple</td>
        <td>purple</td>
        <td>purple</td>
      </tr>
      <tr>
        <td>olive</td>
        <td>olive</td>
        <td>olive</td>
      </tr>
      <tr>
        <td>fuchsia</td>
        <td>fuchsia</td>
        <td>fuchsia</td>
      </tr>
      <tr>
        <td>green</td>
        <td>green</td>
        <td>green</td>
      </tr>
    </table>
  </body>
</html>

  2. Añade clases o ID

    Para dar estilo a una fila concreta necesitas poder seleccionarla. Añade una clase a cada tr (por ejemplo, <tr class="teal">) o a las celdas que quieras. Puedes añadir todas las clases e ID que necesites.

  3. Escribe los estilos

    Da a cada fila el color de texto que nombra. Después juega con el color de fondo, los bordes y el relleno (padding) de las celdas para que la tabla quede lo mejor posible.

  4. Comenta el código

    Encima de cada regla escribe un comentario que explique qué hace:

    /* Filas de color verde azulado: texto y borde del mismo color */
.teal td {
    color: teal;
    border-color: teal;
}
