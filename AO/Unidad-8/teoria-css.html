1. Introducción a CSS

CSS (Cascading Style Sheets o Hojas de Estilo en Cascada) es un lenguaje utilizado para describir la presentación y estilo de un documento HTML. Permite modificar colores, fuentes, márgenes, posiciones, tamaños y mucho más.

Gracias a CSS podemos separar el contenido (HTML) de la presentación (diseño), logrando sitios web más limpios, reutilizables y fáciles de mantener.

CSS es un lenguaje creado para definir la apariencia de los documentos escritos en un lenguaje de marcado, como sería el caso del HTML o el XML. Por tanto, este lenguaje permite cambiar el aspecto de los elementos HTML, ya sea su color, su forma, su posición o cualquier otra característica de índole visual.

Este lenguaje es desarrollado y mantenido por el W3C (Consorcio WWW), por lo que cumple con las especificaciones de estandarización necesarias para ser compatible con los navegadores web. Las siglas CSS son un acrónimo inglés de Cascading Style Sheets (hojas de estilo en cascada).

Para comprobar la compatibilidad de una propiedad CSS o de un elemento HTML se puede usar la herramienta CanIUse. A través de esta herramienta también se puede saber el porcentaje de usuarios que usan un navegador y, por tanto, la cobertura de compatibilidad que tiene el elemento consultado.

Niveles de CSS

El W3C (Consorcio WWW) es una comunidad internacional que desarrolla las especificaciones o normas oficiales del lenguaje CSS. Su objetivo es asegurar el crecimiento y mejora de forma neutral de este lenguaje, así lo independiza de tecnologías propietarias y le añade características de interés.

El W3C lleva años trabajando en la versión CSS3, que tiene como novedad la separación de las nuevas funcionalidades en pequeños módulos para facilitar su implementación en los navegadores web. Esta versión aporta muchos cambios relevantes para todos los niveles de CSS.

Funcionamiento básico del lenguaje CSS

CSS es un lenguaje de hojas de estilos en cascada. Esto quiere decir que permite aplicar estilos a varios elementos HTML y en múltiples documentos de forma masiva. Antes de que el CSS se popularizase, los estilos se aplicaban uno por uno sobre los elementos HTML mediante el uso de atributos.

¿Te imaginas tener 100.000 documentos HTML, cada uno con cinco párrafos, y tener que cambiar el color de cada uno de ellos? Antes de la llegada del CSS, un diseñador web habría tenido que realizar 500.000 modificaciones, seguramente usando algún programa de sustitución de texto; era engorroso.

La gran ventaja del lenguaje CSS es que permite separar el contenido del diseño. Hay varias formas de vincular un diseño CSS a un documento. La más recomendada es utilizando el elemento <link> dentro del <head> del documento. Así, todos los documentos de un sitio web llevarán incrustado el mismo diseño, y se pueden modificar los estilos de forma automática.

Ejemplo de código HTML incluyendo un fichero CSS:

<head>
    <link rel='stylesheet' href='estilos.css'>
</head>

Si ahora, por ejemplo, se quiere indicar que los encabezados (elemento <h1>) deben estar representados de color rojo y los párrafos (elemento <p>) de color azul, en el archivo estilos.css se introducirá el siguiente código: 

h1 {
    color: red;
}
p {
    color: blue;
}

Definir así la apariencia de los elementos HTML ahorra mucho trabajo a los diseñadores web, y evita la edición masiva de documentos HTML. Con los «selectores» se puede apuntar a cualquier elemento y aplicarle estilos mediante propiedades. La sintaxis del CSS es fácil de aprender. 

selector {
    propiedad: valor;
}

CSS tiene varios tipos de selectores: los genéricos, que corresponden al nombre de la etiqueta HTML; los identificadores, mediante el atributo id; y las clases, a través del atributo class. Existen también selectores avanzados, pseudoclases y pseudoelementos que son de gran utilidad.

En CSS es importante dominar el uso de selectores. Sin embargo, existen otros dos conceptos que también conviene comprender para hacer un uso correcto del lenguaje CSS: se trata de la herencia y la cascada, dos conceptos que a pesar de ser diferentes, están estrechamente relacionados.

La herencia tiene que ver en cómo los elementos HTML anidados (hijos) heredan algunas propiedades de sus elementos contenedores (padres). En cambio, la cascada es el algoritmo que controla el resultado final cuando se aplican declaraciones CSS contradictorias sobre el mismo elemento HTML.

Formas de incluir CSS en un documento HTML

Método Descripción Ejemplo
CSS en línea Se aplica directamente dentro del atributo style de un elemento HTML.
<p style="color: red;">Texto rojo</p>
CSS interno Se escribe dentro de una etiqueta <style> en el <head>.
<style>
  p { color: green; }
</style>
CSS externo Se enlaza un archivo .css desde el <head> del documento.
<link rel="stylesheet" href="estilos.css">

Ejemplo con CSS interno

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Ejemplo CSS</title>
    <style>
        body {
            background-color: #f0f0f0;
            font-family: Arial, sans-serif;
        }
        h1 {
            color: navy;
        }
    </style>

<body>
    <h1>Hola, mundo CSS</h1>
    <p>Este es un párrafo con estilo.</p>
</body>
</html>

Este ejemplo demuestra cómo aplicar estilos directamente dentro del archivo HTML usando la etiqueta <style>.

2. Elementos importantes de CSS

CSS se compone de reglas que se aplican a elementos HTML para definir su estilo visual. Cada regla tiene uno o más selectores y un conjunto de declaraciones formadas por propiedades y valores.

Estructura de una regla CSS

selector {
    propiedad: valor; /* Declaración */
    propiedad: valor; /* Declaración */
}

Ejemplo:

p {
    color: red;
} /* → Aplica el color rojo a todos los párrafos. */

Propiedades fundamentales de CSS

Propiedad Descripción Ejemplo
color Define el color del texto. color: blue;
background-color Color de fondo del elemento. background-color: yellow;
font-size Tamaño del texto. font-size: 16px;
font-family Define la fuente del texto. font-family: Arial, sans-serif;
font-weight Grosor de la fuente. font-weight: bold;
font-style Estilo de la fuente. font-style: italic;
text-decoration Decoración del texto (subrayado, tachado, etc.). text-decoration: underline;
margin Espacio exterior del elemento. margin: 10px;
padding Espacio interior (entre el contenido y el borde). padding: 15px;
border Define el borde del elemento. border: 1px solid black;
width Ancho del elemento. width: 200px;
height Alto del elemento. height: 100px;
display Tipo de visualización del elemento (block, inline, inline-block, flex, grid, etc.). display: block;
float Posiciona un elemento a la izquierda o derecha de su contenedor, permitiendo que otros elementos floten a su alrededor. float: left;
position Método de posicionamiento de un elemento (static, relative, absolute, fixed, sticky). position: relative;
top, right, bottom, left Se utilizan con position para especificar el desplazamiento del elemento. top: 20px;

Unidades de Medida en CSS

En CSS, las unidades de medida se utilizan para especificar la longitud, el tamaño y otras dimensiones de los elementos. Es importante comprender las diferentes unidades disponibles para lograr el diseño deseado y adaptabilidad.

Unidades Absolutas

Las unidades absolutas representan un valor fijo y no varían según el entorno. Sin embargo, en el contexto web, la más común es el píxel (px), aunque las otras son estándares físicos.

  • px (píxel): Es la unidad más común en la web. Representa un punto en la pantalla del dispositivo. 
    font-size: 16px;
  • pt (punto): Tradicionalmente usado en imprenta (1 punto = 1/72 de pulgada). No es tan común en la web para la visualización en pantalla. 
    font-size: 12pt;
  • cm (centímetro), mm (milímetro), in (pulgada): Unidades físicas. Raramente se usan para diseño web, ya que el tamaño de la pantalla varía. 
    width: 10cm;

Unidades Relativas

Las unidades relativas basan su valor en otro valor, lo que las hace muy útiles para crear diseños flexibles y adaptables.

  • em: Relativo al tamaño de la fuente del elemento padre. Si el padre tiene un font-size de 16px, entonces 1em será 16px en el hijo (a menos que el hijo también defina su propio font-size). 
    .padre { font-size: 16px; }
.hijo { font-size: 1.5em; /* → 24px (1.5 * 16) */ }
  • rem (root em): Relativo al tamaño de la fuente del elemento raíz (<html>). Esto ayuda a mantener una escala de fuente consistente en toda la página. 
    html { font-size: 10px; }
body { font-size: 1.6rem; /* → 16px (1.6 * 10) */ }
  • %: Porcentaje. A menudo relativo al tamaño del elemento padre. Por ejemplo, el width: 50%; hará que un elemento ocupe la mitad del ancho de su contenedor padre. 
    .contenedor { width: 400px; }
.elemento { width: 50%; /* → 200px */ }
  • vw (viewport width): Relativo al 1% del ancho de la ventana del navegador. 100vw es el ancho completo de la ventana. 
    .ancho-completo { width: 100vw; }
  • vh (viewport height): Relativo al 1% de la altura de la ventana del navegador. 100vh es la altura completa de la ventana. 
    .alto-completo { height: 100vh; }
  • vmin (viewport minimum): Relativo al 1% de la dimensión más pequeña de la ventana (ancho o alto). 
    .cuadrado-minimo { width: 50vmin; height: 50vmin; /* Siempre será un cuadrado basado en la dimensión más pequeña */ }
  • vmax (viewport maximum): Relativo al 1% de la dimensión más grande de la ventana (ancho o alto). 
    .elemento-maximo { font-size: 10vmax; /* La fuente crecerá según la dimensión más grande */ }

Consideraciones

La elección de la unidad de medida depende del contexto y del efecto que se quiera lograr. Las unidades relativas son generalmente preferibles para crear diseños adaptables que funcionen bien en diferentes dispositivos y tamaños de pantalla. Los rem son especialmente útiles para mantener una escala de texto consistente, mientras que las unidades de viewport (vw, vh, vmin, vmax) son ideales para diseños que ocupan toda la ventana del navegador.

Ejemplo práctico con varias propiedades

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Estilos CSS básicos</title>
    <style>
        .caja {
            background-color: #e0f7fa;
            color: #006064;
            font-size: 18px;
            padding: 20px;
            margin: 15px 0;
            border: 2px dashed #0097a7;
            text-align: center;
        }
    </style>
</head>
<body>
    <div class="caja">
        ¡Hola! Soy una caja estilizada con CSS 😊
    </div>
</body>
</html>

Este ejemplo utiliza varias propiedades básicas de CSS para dar estilo a un <div>, incluyendo color, fondo, bordes y espaciado.

La Jerarquía (Especificidad) en CSS

Cuando varios estilos intentan aplicarse al mismo elemento, el navegador sigue una jerarquía para determinar cuál prevalece. Esta jerarquía se basa en la especificidad de los selectores.

De manera general, los estilos se aplican en el siguiente orden de menor a mayor prioridad:

  1. Estilos por defecto del navegador: Son los estilos básicos que el navegador aplica a los elementos si no se especifica ningún otro.
  2. Estilos en archivos CSS externos (enlazados): Los estilos definidos en archivos .css enlazados en la sección <head> del HTML.
  3. Estilos internos (en la etiqueta <style>): Los estilos definidos directamente dentro de la etiqueta <style> en el documento HTML.
  4. Estilos en línea: Los estilos aplicados directamente a un elemento HTML usando el atributo style. Estos tienen la mayor prioridad.

Selectores y Especificidad:

Dentro de los estilos en archivos CSS o internos, la especificidad de los selectores también juega un papel importante. Aquí tienes una idea general de la prioridad:

  1. Selectores de tipo (elementos): Como p, h1, div. Son los menos específicos.
  2. Selectores de clase: Como .container, .text-primary. Son más específicos que los selectores de tipo.
  3. Selectores de ID: Como #mi-elemento. Son aún más específicos que los selectores de clase.
  4. Estilos en línea: (Mencionados anteriormente) Tienen la mayor especificidad.
Ejemplo para ilustrar la especificidad:
<div id="miDiv" class="contenedor texto-rojo" style="color: green;">Este texto tiene varios estilos.</div>
/* Estilo para todos los div */
div {
    color: blue;
}

/* Estilo para la clase texto-rojo */
.texto-rojo {
    color: red;
}

/* Estilo para el ID miDiv */
#miDiv {
    color: orange;
}

En este ejemplo, el texto dentro del <div> aparecerá en verde. Esto se debe a que el estilo en línea (style="color: green;") tiene la mayor prioridad. Si elimináramos el estilo en línea, el texto sería naranja, ya que el selector de ID (#miDiv) es más específico que el selector de clase (.texto-rojo), que a su vez es más específico que el selector de tipo (div).

3. Propiedades

En CSS, podemos definir diversas propiedades para los elementos HTML, y a cada propiedad asignarle un valor específico. Por ejemplo, la propiedad color (color del texto) puede tener valores como red, blue, #FF0000, etc.

A continuación, exploraremos algunas de las propiedades más importantes de CSS, cómo se utilizan y los valores que pueden tomar. El objetivo es demostrar cómo puedes controlar el aspecto visual de tus elementos web principalmente a través de estilos CSS, manteniendo tu HTML más enfocado en la estructura.

Cubriremos las siguientes propiedades:

  • Fuentes y Texto
  • Color
  • Fondo (Background)
  • Espaciado (Margin y Padding)
  • Dimensiones (Ancho)
  • Borde (Border)
  • Posicionamiento y Visualización de Elementos

Fuentes y Texto

Estas propiedades permiten controlar la apariencia visual del texto dentro de los elementos HTML, incluyendo párrafos, encabezados y enlaces. Las propiedades más comunes son:

font-family

Define la fuente tipográfica para el texto. Se recomienda especificar una lista de fuentes, separadas por comas, para que el navegador pueda usar una fuente alternativa si la primera no está disponible en el sistema del usuario. La lista debe terminar con una familia genérica (serif, sans-serif, monospace, cursive, fantasy). 

.ejemplo-fuente {
    font-family: "Arial", "Verdana", sans-serif;
}

Si el usuario no tiene Arial o Verdana, se usará cualquier fuente sans-serif disponible en su sistema.

font-style

Especifica si el texto debe mostrarse en cursiva. Los valores comunes son normal y italic. 

.ejemplo-cursiva {
    font-style: italic;
}

font-weight

Define el grosor o "negrita" de la fuente. Los valores comunes incluyen normal, bold, y valores numéricos de 100 a 900 (en múltiplos de 100). bold es equivalente a 700. 

.ejemplo-negrita {
    font-weight: bold;
}

.ejemplo-fino {
    font-weight: 300; /* Requiere que la fuente soporte este grosor */
}

font-size

Establece el tamaño de la fuente. Es crucial elegir unidades adecuadas para la web, como px, em, rem, o %, que permitan adaptabilidad. Las unidades absolutas como pt, cm, etc., no son ideales para la visualización en pantalla ya que no se escalan con la configuración del usuario o el zoom del navegador de forma predecible (Ver sección "Unidades de Medida" del ejemplo anterior para más detalle). 

.ejemplo-tamano {
    font-size: 16px; /* Tamaño fijo en píxeles */
}

.ejemplo-relativo {
    font-size: 1.2rem; /* 1.2 veces el tamaño de fuente del elemento raíz */
}

Propiedad abreviada font

Esta es una propiedad abreviada que permite establecer varias propiedades de fuente en una sola declaración. El orden es importante y generalmente sigue este patrón (los valores entre corchetes son opcionales): [font-style] [font-weight] font-size font-family. 

.ejemplo-font-shorthand {
    font: italic bold 16px "Arial", sans-serif;
}

.ejemplo-font-shorthand2 {
    font: 1em sans-serif; /* Solo tamaño y familia, el resto por defecto */
}

text-decoration

Se usa para añadir decoraciones al texto, comúnmente para eliminar el subrayado de los enlaces o añadirlo a otros elementos. Los valores incluyen none (sin decoración), underline (subrayado), overline (línea por encima) y line-through (tachado). El valor blink está obsoleto y no se recomienda usar. 

a {
    text-decoration: none; /* Elimina el subrayado de los enlaces */
}

.ejemplo-tachado {
    text-decoration: line-through;
    color: red; /* Se pueden combinar propiedades */
}

text-align

Define la alineación horizontal del contenido en línea (como texto e imágenes) dentro de un elemento de bloque. Los valores posibles son left, right, center y justify. 

.parrafo-centrado {
    text-align: center;
}

.parrafo-justificado {
    text-align: justify;
}

text-indent

Especifica la sangría de la primera línea de un bloque de texto. Su valor se define con una unidad de medida (como px, em, %) o un valor relativo.

p {
    text-indent: 30px; /* La primera línea del párrafo tendrá una sangría de 30px */
}

Color

La propiedad color establece el color del texto de un elemento.

Los colores pueden especificarse de varias formas:

  • Nombres de color: Usando nombres predefinidos como red, blue, black, white, etc. Hay una amplia lista de nombres de color estándar.
  • Valores Hexadecimales: Usando el formato #RRGGBB o #RGB, donde RR, GG, BB son valores hexadecimales para Rojo, Verde y Azul (00 a FF).
  • Valores RGB/RGBA: Usando el formato rgb(rojo, verde, azul) o rgba(rojo, verde, azul, alfa), donde rojo, verde, azul son valores numéricos (0-255 o 0%-100%) y alfa es la opacidad (0 a 1).
  • Valores HSL/HSLA: Usando el formato hsl(tono, saturacion, luminosidad) o hsla(tono, saturacion, luminosidad, alfa).

Ejemplos de Propiedad color

.texto-rojo-nombre {
    color: red; /* Usando nombre de color */
}

.texto-rojo-hex {
    color: #FF0000; /* Usando valor hexadecimal */
}

.texto-rojo-rgb {
    color: rgb(255, 0, 0); /* Usando valor RGB */
}

.texto-semitransparente {
    color: rgba(0, 0, 0, 0.5); /* Texto negro con 50% de opacidad */
}

Fondo (Background)

Las propiedades de fondo controlan el color o la imagen que aparece detrás del contenido de un elemento.

background-color

Establece el color de fondo de un elemento. El valor se especifica de la misma manera que el color de texto (nombres, hex, RGB, etc.).

body {
    background-color: #f0f0f0; /* Color de fondo para toda la página */
}

.caja-con-fondo {
    background-color: lightblue;
}

background-image

Establece una imagen como fondo de un elemento. Se utiliza la función url() para especificar la ruta de la imagen.

body {
    background-image: url("imagenes/fondo-pagina.jpg");
}

.elemento-con-icono {
    background-image: url("../iconos/check.png");
}

La ruta puede ser absoluta (/imagenes/fondo.jpg) o relativa (../iconos/check.png).

Propiedad abreviada background

Esta propiedad es una abreviatura para varias propiedades de fondo (background-color, background-image, background-repeat, background-position, background-size, etc.). El orden no es estrictamente fijo para todos los valores, pero es común especificar primero la imagen y luego el color de fondo. 

body {
    /* Imagen de fondo (sin repetir), centrada, con color de fondo sólido */
    background: url("imagenes/fondo-pagina.jpg") no-repeat center center / cover, #f0f0f0;
}

.caja-resumida {
    /* Imagen y color de fondo */
    background: url("graficos/patron.png") white;
}

Es recomendable definir un background-color junto con un background-image para asegurar que haya un fondo visible si la imagen no se carga.

Espaciado (Margin y Padding)

Estas propiedades controlan el espacio alrededor del contenido de un elemento.

  • padding: Crea espacio *dentro* del borde del elemento, entre el contenido y el borde.
  • margin: Crea espacio *fuera* del borde del elemento, separándolo de otros elementos adyacentes.

padding (Relleno Interior)

Controla el espacio entre el contenido y el borde de un elemento. Puede definirse para los cuatro lados (arriba, derecha, abajo, izquierda) individualmente o usando la propiedad abreviada.

/* Propiedades individuales */
.caja-padding {
    padding-top: 10px;
    padding-right: 15px;
    padding-bottom: 10px;
    padding-left: 15px;
}

/* Propiedad abreviada */
.caja-padding-shorthand {
    padding: 10px 15px; /* Arriba/Abajo: 10px, Izquierda/Derecha: 15px */
}

.caja-padding-todos-lados {
    padding: 20px; /* 20px en los 4 lados */
}

Con la abreviada, si se dan 4 valores: Arriba Derecha Abajo Izquierda. Si se dan 2 valores: Arriba/Abajo Izquierda/Derecha. Si se da 1 valor: Los 4 lados.

margin (Margen Exterior)

Controla el espacio alrededor de un elemento, separándolo de otros. Se define de manera similar al padding, individualmente o usando la propiedad abreviada. 

/* Propiedades individuales */
.elemento-margin {
    margin-top: 20px;
    margin-bottom: 20px;
    margin-left: auto; /* Centra el elemento si tiene un ancho definido */
    margin-right: auto;
}

/* Propiedad abreviada */
.elemento-margin-shorthand {
    margin: 1em 0; /* Arriba/Abajo: 1em, Izquierda/Derecha: 0 */
}

Los márgenes verticales de elementos adyacentes pueden colapsar. Usar margin: auto; en los lados izquierdo y derecho es una técnica común para centrar un elemento de bloque dentro de su contenedor, siempre que el elemento tenga un width definido.

Dimensiones

width (Ancho)

Define el ancho del área de contenido de un elemento. Se puede especificar con unidades de longitud (px, em, rem, vw, etc.) o con porcentajes (%), que son relativos al ancho del contenedor padre. El valor auto (por defecto) permite que el navegador calcule el ancho.

.caja-ancho-fijo {
    width: 300px;
}

.caja-ancho-relativo {
    width: 80%; /* Ocupa el 80% del ancho del contenedor padre */
}

.imagen-ancho-maximo {
    max-width: 100%; /* La imagen nunca será más ancha que su contenedor */
    height: auto; /* Mantiene la proporción original */
}

También existen las propiedades min-width y max-width para controlar el rango de anchos posibles, lo cual es fundamental para el diseño web responsivo.

height (Alto)

Define el alto del área de contenido de un elemento. Se especifica de forma similar a width, usando unidades de longitud (px, em, rem, vh, etc.) o porcentajes (%). El valor auto (por defecto) permite que el navegador calcule el alto basado en el contenido.

.caja-alto-fijo {
    height: 150px;
}

.seccion-pantalla-completa {
    height: 100vh; /* Ocupa el 100% del alto de la ventana (viewport) */
}

De manera similar a width, existen min-height y max-height para controlar el rango de alturas posibles.

Borde (Border)

Las propiedades de borde permiten definir el grosor, estilo y color del borde alrededor de un elemento.

border-width (Grosor del Borde)

Define el grosor del borde. Se puede especificar con unidades de longitud (px, em, etc.) o con palabras clave predefinidas como thin, medium, thick.

/* Aplicar el mismo grosor a los 4 lados */
.caja-borde-ancho {
    border-width: 2px;
}

/* Grosor diferente para cada lado (Arriba Derecha Abajo Izquierda) */
.caja-bordes-varios {
    border-width: 1px 2px 3px 4px;
}

/* Grosor solo para un lado */
.caja-borde-superior {
    border-top-width: 5px;
}

border-style (Estilo del Borde)

Define el estilo de la línea del borde. Esta propiedad es fundamental; un borde no será visible a menos que se defina un estilo (incluso si se definen grosor y color). Valores comunes incluyen:

  • none: Sin borde (valor por defecto).
  • solid: Una línea recta sólida.
  • dashed: Una línea de guiones.
  • dotted: Una línea de puntos.
  • double: Un borde doble.
  • groove, ridge, inset, outset: Efectos 3D (dependen del color).
.caja-borde-solido {
    border-style: solid;
}

.caja-borde-punteado {
    border-style: dotted;
}

Al igual que con border-width, existen propiedades para estilos individuales por lado: border-top-style, border-right-style, etc.

border-color (Color del Borde)

Define el color del borde. Los valores se especifican de la misma manera que el color de texto o fondo (nombres, hex, RGB, etc.).

.caja-borde-azul {
    border-color: blue;
}

.caja-bordes-colores {
     /* Color diferente para cada lado (Arriba Derecha Abajo Izquierda) */
    border-color: red green blue yellow;
}

Propiedades individuales por lado: border-top-color, border-right-color, etc.

Propiedad abreviada border

La propiedad abreviada border es la forma más común y concisa de definir un borde. Combina border-width, border-style y border-color en una sola declaración. El orden recomendado es: [border-width] [border-style] [border-color]. 

.caja-borde-completo {
    border: 1px solid black; /* Grosor, Estilo, Color */
    padding: 10px; /* Añadimos padding para separar el contenido del borde */
}

.caja-sin-borde-abajo {
    border: 2px solid red; /* Borde en todos los lados por defecto */
    border-bottom: none; /* Sobrescribimos el borde inferior */
}

Usar la abreviada es más eficiente. Recuerda que el border-style es obligatorio para que el borde sea visible.

Posicionamiento y Visualización de Elementos

Además de controlar el aspecto de los elementos (color, tamaño, texto), CSS es fundamental para definir cómo se muestran y dónde se colocan en la página. Las propiedades display, float y position, junto con las propiedades de desplazamiento, son clave para controlar el layout y la disposición de los elementos.

display

Esta propiedad fundamental define el tipo de caja de renderizado que genera un elemento. Controla cómo el elemento se comporta en el flujo normal del documento y cómo interactúa con otros elementos.

Los valores más comunes son:

  • block: El elemento genera una caja de bloque. Ocupa todo el ancho disponible y siempre comienza en una nueva línea. Ejemplos: <div>, <p>, <h1>.
  • inline: El elemento genera una o más cajas en línea. No comienza en una nueva línea y solo ocupa el ancho necesario para su contenido. No se pueden controlar width, height, margin-top, ni margin-bottom. Ejemplos: <span>, <a>, <strong>.
  • inline-block: El elemento se comporta como un elemento en línea en relación con sus elementos hermanos (no comienza en una nueva línea), pero dentro de sí mismo se comporta como un bloque, permitiendo controlar width, height y los márgenes verticales/horizontales.
  • none: El elemento y su contenido no se muestran en absoluto y no ocupan espacio en el layout.
  • flex, grid: Valores que convierten el contenedor en un Flex Container o Grid Container, respectivamente, habilitando potentes modelos de layout modernos.
.elemento-bloque {
    display: block;
}

.elemento-inline {
    display: inline;
}

.elemento-inline-bloque {
    display: inline-block;
    width: 150px;
    height: 100px;
    margin: 10px;
}

.elemento-oculto {
    display: none;
}

float

La propiedad float posiciona un elemento (generalmente una imagen o un bloque de texto) a la izquierda o derecha dentro de su contenedor, permitiendo que el contenido en línea (como texto) fluya alrededor de él. Originalmente usado para maquetación básica, hoy en día Flexbox y Grid son a menudo preferidos para layouts complejos.

  • left: Flota el elemento a la izquierda.
  • right: Flota el elemento a la derecha.
  • none: El elemento no flota (valor por defecto).
.imagen-flotante {
    float: right; /* La imagen se moverá a la derecha */
    margin-left: 15px; /* Añadir espacio a su izquierda */
}

Si utilizas float, a menudo necesitarás usar la propiedad clear en un elemento posterior para detener el flujo de contenido y evitar que se solape con el elemento flotante.

position

Esta propiedad define el método de posicionamiento de un elemento en el documento. Funciona conjuntamente con las propiedades top, right, bottom y left.

  • static: Es el valor por defecto. El elemento se posiciona según el flujo normal del documento. Las propiedades top, right, bottom, left y z-index no tienen efecto.
  • relative: El elemento se posiciona según el flujo normal, pero su posición final puede ser ajustada *relativa a su posición original* utilizando top, right, bottom, left. El espacio que ocupaba en el flujo normal se mantiene.
  • absolute: El elemento se retira del flujo normal del documento y se posiciona *relativo a su ancestro posicionado más cercano* (un ancestro con position distinto de static). Si no tiene ancestros posicionados, se posiciona relativo al viewport inicial. Las propiedades top, right, bottom, left definen su desplazamiento desde los bordes de referencia.
  • fixed: El elemento se retira del flujo normal y se posiciona *relativo al viewport*. Permanece en su posición incluso cuando la página se desplaza. Es útil para crear encabezados o pies de página fijos. Las propiedades top, right, bottom, left definen su desplazamiento desde los bordes del viewport.
  • sticky: El elemento se posiciona según el flujo normal hasta que su contenedor se desplaza hasta un umbral especificado (usando top, right, bottom, o left), momento en el que se "pega" al viewport o a su contenedor, comportándose de forma similar a fixed. 
/* Un contenedor para demostrar position: absolute */
.contenedor-relativo {
    position: relative; /* Este es el ancestro posicionado */
    width: 300px;
    height: 200px;
    border: 1px solid blue;
    padding: 10px;
}

/* Elementos con distintos tipos de posicionamiento */
.elemento-estatico {
    /* position: static; es el valor por defecto, no suele declararse explícitamente */
    background-color: lightgray;
}

.elemento-relativo {
    position: relative;
    top: 10px; /* Se mueve 10px hacia abajo desde su posición normal */
    left: 10px; /* Se mueve 10px hacia la derecha desde su posición normal */
    background-color: lightgreen;
}

.elemento-absoluto {
    position: absolute;
    top: 20px; /* 20px desde el borde superior del contenedor relativo */
    right: 20px; /* 20px desde el borde derecho del contenedor relativo */
    background-color: lightcoral;
}

.elemento-fijo {
    position: fixed;
    bottom: 10px; /* 10px desde el borde inferior del viewport */
    right: 10px; /* 10px desde el borde derecho del viewport */
    background-color: yellow;
    padding: 5px;
}

/* Ejemplo conceptual de sticky (requiere scroll para verse el efecto completo) */
.elemento-sticky {
    position: sticky;
    top: 0; /* Se pegará en la parte superior del viewport cuando se desplace */
    background-color: lightblue;
    padding: 10px;
    margin-bottom: 15px;
}

La propiedad z-index (no cubierta aquí) se utiliza para controlar el orden de apilamiento de los elementos posicionados (quién aparece encima de quién).

top, right, bottom, left

Estas cuatro propiedades se utilizan para especificar el desplazamiento final de un elemento que tiene una propiedad position con valor relative, absolute, fixed, o sticky.

  • top: Desplaza desde el borde superior de referencia.
  • right: Desplaza desde el borde derecho de referencia.
  • bottom: Desplaza desde el borde inferior de referencia.
  • left: Desplaza desde el borde izquierdo de referencia.

El "borde de referencia" depende del valor de position:

  • Para position: relative;, el borde de referencia es la posición original del elemento.
  • Para position: absolute;, el borde de referencia es el padding edge del ancestro posicionado más cercano (o del viewport inicial).
  • Para position: fixed;, el borde de referencia es el viewport.
  • Para position: sticky;, actúan como umbral de desplazamiento dentro del contenedor o viewport.
.caja-posicionada {
    position: absolute; /* O relative, fixed, sticky */
    top: 50px; /* Desplazado 50px desde arriba */
    left: 100px; /* Desplazado 100px desde la izquierda */
    width: 100px;
    height: 100px;
    background-color: plum;
}

4. Selectores

Los selectores en CSS indican a qué elementos HTML se aplicarán las reglas de estilo. A continuación se muestran los selectores más comunes con ejemplos.

1. Selector de tipo o etiqueta

Selecciona todos los elementos de un tipo determinado.

p {
    color: red;
}

Ejemplo: Aplica color rojo a todos los párrafos <p>.

2. Selector de clase

Selecciona elementos que tienen un atributo class específico. Se indica con un punto (.).

.destacado {
    background-color: yellow;
}
<p class="destacado">Texto importante</p>

3. Selector de ID

Selecciona un único elemento con un id específico. Se indica con una almohadilla (#).

#titulo {
    font-size: 24px;
}
<h1 id="titulo">Bienvenidos</h1>

4. Selector universal

Selecciona todos los elementos del documento.

* {
    margin: 0;
    padding: 0;
}

Ejemplo: Se usa para eliminar márgenes y rellenos por defecto.

5. Selector de descendiente

Selecciona elementos que estén dentro de otro elemento específico.

article p {
    color: green;
}

Ejemplo: Aplica color verde a los <p> que estén dentro de un <article>.

6. Selectores combinados y avanzados

  • h1, h2: selecciona varios elementos a la vez.
  • a:hover: selecciona cuando el usuario pasa el ratón por encima.
  • ul > li: selecciona solo los elementos hijos directos.
a:hover {
    text-decoration: underline;
}

Ejemplo: Subraya los enlaces al pasar el ratón.

5. Selectores de etiqueta

Los selectores de etiqueta aplican estilos a todos los elementos HTML de un tipo específico, como p, h1 o a.

Ventajas

  • Fáciles de usar.
  • Permiten aplicar estilos generales rápidamente.
  • Útiles para mantener un estilo uniforme.

Limitaciones

  • Demasiado generales en algunos casos.
  • No sirven para personalizaciones específicas.

Ejemplo de uso

h1 {
    color: navy;
    font-family: Arial, sans-serif;
}

p {
    font-size: 16px;
    line-height: 1.5;
}

a {
    color: green;
    text-decoration: none;
}
<h1>Título principal</h1>
<p>Este es un párrafo de texto normal.</p>
<a href="#">Enlace sin subrayado</a>

Selector combinado

Puedes combinar una etiqueta con una clase para mayor precisión:

p.intro {
    font-weight: bold;
}
<p class="intro">Este párrafo es introductorio.</p>

6. Selectores de clase

Un selector de clase permite aplicar estilos a uno o varios elementos que comparten una misma clase. Se indica con un punto (.) seguido del nombre de la clase.

Ventajas

  • Permiten reutilizar estilos en diferentes elementos.
  • Dan mayor flexibilidad que los selectores de etiqueta.

Ejemplo de uso

.importante {
    background-color: yellow;
    font-weight: bold;
}
<p class="importante">Este texto es importante.</p>
<div class="importante">También puedo usar esta clase en un div.</div>

7. Selectores de ID

El selector de ID se usa para aplicar estilos a un único elemento identificado por su atributo id. Se indica con una almohadilla (#) seguida del nombre del ID.

Importante

El ID debe ser único en cada documento HTML.

Ejemplo de uso

#cabecera {
    background-color: lightgray;
    padding: 10px;
}
<header id="cabecera">Encabezado principal</header>

8. Selectores descendientes y combinadores

Los combinadores en CSS permiten definir relaciones entre elementos HTML. Son esenciales para aplicar estilos específicos según la posición de los elementos en el DOM.

Selector Nombre Relación Ejemplo
elemento1 elemento2 Descendiente Selecciona todos los elemento2 dentro de elemento1 (a cualquier nivel) div p → Todos los <p> dentro de <div>
elemento1 > elemento2 Hijo directo Solo los hijos directos de elemento1 ul > li → Solo <li> hijos directos de <ul>
elemento1 + elemento2 Hermano adyacente Selecciona el elemento2 que esté justo después de elemento1 h1 + p → El primer <p> tras un <h1>
elemento1 ~ elemento2 Hermanos generales Selecciona todos los elemento2 que estén después de elemento1, como hermanos h2 ~ p → Todos los <p> tras un <h2>
* Universal Selecciona todos los elementos * { margin: 0; } → Reinicia márgenes de todos los elementos

Ejemplo práctico combinado

<style>
    div p {
        color: blue;
    }

    div > p {
        font-weight: bold;
    }

    h2 + p {
        background-color: yellow;
    }

    h2 ~ p {
        font-style: italic;
    }

    * {
        box-sizing: border-box;
    }
</style>

<div>
    <p>Soy hijo directo y descendiente de un div.</p>
    <section>
        <p>Soy un descendiente, pero no hijo directo.</p>
    </section>
</div>

<h2>Título</h2>
<p>Soy hermano adyacente del h2.</p>
<p>Soy hermano general del h2.</p>

Este ejemplo muestra cómo aplicar distintos estilos según la relación estructural entre elementos. Puedes visualizar cómo se comporta cada selector en un navegador para entenderlo mejor.
