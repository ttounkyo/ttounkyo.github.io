Unidad 3. Actividades

En cada actividad despliegas una aplicación con una tecnología distinta, del «Hola Mundo» a dejarla en producción detrás de Nginx. Hazlas en orden: cada una aprovecha lo que instalaste en la anterior.

Cómo trabajar cada actividad:
  1. Lee primero el apartado de teoría que se indica.
  2. Trabaja en tu servidor Debian 13 (máquina virtual o VPS) conectado por SSH. Donde ponga IP-DE-TU-SERVIDOR o tuUsuario, escribe los tuyos.
  3. Copia los comandos con el botón Copiar y, en cada paso, mira el cuadro Comprueba: dice qué debe salir en la terminal o en el navegador. No sigas hasta que te salga.
  4. Haz las capturas que se piden y pégalas en tu documento de entrega con el título del paso encima.
  5. Antes de entregar, marca la lista de comprobación del final. Tu avance se guarda en este navegador.
Actividad Qué practicas Teoría Tu avance
3.1. Node.js y Express Instalar Node.js, crear un «Hola Mundo» con Express, desplegar una API con MariaDB, mantenerla con PM2 y ponerle Nginx delante. 6. Node.js con Express Sin empezar
3.2. Flask y Gunicorn Entornos virtuales de Python, un blog con Flask y SQLite, Gunicorn como servicio de systemd y Nginx como proxy inverso. 7. Aplicaciones Python Sin empezar
3.3. Node.js con Docker Instalar Docker, escribir un Dockerfile, ejecutar un contenedor y levantar WordPress con Docker Compose. 8. Contenedores: Docker Sin empezar
3.4. Jakarta EE con WildFly Instalar el JDK, Maven y WildFly, crear un servlet, empaquetarlo en un WAR y desplegarlo. 5. Aplicaciones Java Sin empezar
3.5. Django Un proyecto Django con su panel de administración, Gunicorn con socket Unix y Nginx sirviendo los estáticos. 7. Aplicaciones Python Sin empezar
