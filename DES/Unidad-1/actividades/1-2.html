Actividad 1.2. Conexión SSH con PuTTY y claves

Vas a instalar PuTTY, generar un par de claves con PuTTYgen, instalar la clave pública en tu servidor Debian y conectarte con la clave privada, sin escribir la contraseña.

Lo que vas a practicar

  • El archivo /etc/ssh/sshd_config
  • Instalar PuTTY y generar claves con PuTTYgen
  • El archivo ~/.ssh/authorized_keys y sus permisos
  • Guardar una sesión de PuTTY con la clave privada

Antes de empezar

  • Teoría: 3. Autenticación y cifrado en SSH y 4. Configuración del servidor SSH
  • Tu servidor de la actividad 1.1 funcionando, con openssh-server instalado.
  • PuTTY es para Windows. Si usas Mac o Linux, mira la nota del paso 3.

Paso a paso

Las capturas son de PuTTY 0.83 en Windows. Si tienes una versión más nueva, las ventanas pueden cambiar un poco, pero las opciones son las mismas.

  1. Revisa la configuración del servidor SSH

    Conéctate a tu servidor (como en la actividad 1.1) y abre la configuración de SSH:

    cd /etc/ssh
sudo nano sshd_config

    Comprueba que la línea PubkeyAuthentication yes no está comentada (sin # delante) y que AuthorizedKeysFile apunta a .ssh/authorized_keys. Si cambias algo, guarda y reinicia el servicio:

    sudo systemctl restart ssh

  2. Instala PuTTY

    Descarga el instalador de 64 bits (.msi) desde la página oficial de PuTTY y ejecútalo. Deja la carpeta por defecto (C:\Program Files\PuTTY\) y las opciones que vienen marcadas.

  3. Genera el par de claves con PuTTYgen

    Abre PuTTYgen (se instala con PuTTY). Elige el tipo de clave: EdDSA (Ed25519), que es la más moderna, o RSA de 2048 bits o más, como en las capturas. Pulsa Generate y mueve el ratón por el recuadro en blanco hasta que se llene la barra: así se genera aleatoriedad para la clave.

    Cuando termine, puedes escribir una frase de paso (Key passphrase) para proteger la clave privada. Después pulsa Save private key y guarda el archivo .ppk en una carpeta tuya. Guarda también la pública con Save public key.

    El archivo .ppk es tu clave privada: no lo compartas, no lo subas al servidor ni lo metas en la entrega.
    ¿Usas Mac o Linux?

    No necesitas PuTTY: genera las claves en la terminal de tu ordenador y cópialas al servidor con ssh-copy-id (hace por ti los pasos 4 a 6):

    ssh-keygen -t ed25519
ssh-copy-id usuario@192.168.1.28
ssh usuario@192.168.1.28

  4. Copia la clave pública

    En PuTTYgen, selecciona todo el texto del recuadro Public key for pasting into OpenSSH authorized_keys file (desde ssh-rsa o ssh-ed25519 hasta el final) y cópialo.

    Copia la clave de este recuadro, no del archivo que guardas con Save public key: ese archivo tiene otro formato que el servidor no entiende en authorized_keys. Si cierras PuTTYgen, pulsa Load y abre tu .ppk para volver a verla.

  5. Conéctate con PuTTY y tu contraseña

    Abre PuTTY. En Host Name escribe usuario@IP_DEL_SERVIDOR, deja el puerto 22 y el tipo de conexión SSH. Pulsa Open.

    La primera vez, PuTTY avisa de que no conoce la huella del servidor. Comprueba que la IP es la de tu servidor y pulsa Accept. Después escribe tu contraseña.

  6. Instala la clave pública en el servidor

    Ya dentro del servidor, crea la carpeta .ssh (si no existe) y abre el archivo authorized_keys:

    mkdir -p ~/.ssh
nano ~/.ssh/authorized_keys

    Pega la clave pública en una sola línea. En PuTTY se pega con el botón derecho del ratón. Guarda con Ctrl+O y Intro, y sal con Ctrl+X.

    Por último, ajusta los permisos. Si la carpeta o el archivo tienen permisos demasiado abiertos, SSH no usará la clave:

    chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys

  7. Configura PuTTY con la clave privada

    Cierra la sesión (exit) y vuelve a abrir PuTTY. Ve a Connection → SSH → Auth → Credentials y, en Private key file for authentication, pulsa Browse y elige tu archivo .ppk.

    Vuelve a Session, escribe usuario@IP_DEL_SERVIDOR, pon un nombre en Saved Sessions (por ejemplo, DES) y pulsa Save. Así no tendrás que configurarla cada vez.

  8. Conéctate con la clave

    Abre la sesión guardada. Esta vez PuTTY no te pide la contraseña del usuario: verás el mensaje Authenticating with public key (si pusiste frase de paso, te pedirá esa frase).
